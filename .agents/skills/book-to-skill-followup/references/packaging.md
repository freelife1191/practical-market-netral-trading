# 제작 도구와 책 결과물의 배포 분리

## 실행 위치

`book-to-skill-followup`은 제작·검수 도구다. 기본 실행은 책 결과물 저장소 밖의 제작 작업 공간에서 하며, 현재 읽은 스킬의 절대 경로를 `FOLLOWUP_SKILL_DIR`로 사용한다. 책 프로젝트는 `--project`, 지식 스킬은 `--skill`로 지정한다. 제작자의 cwd나 도구 설치 위치를 책 결과물의 설치 경로로 복제하지 않는다.

완성된 책 결과물에는 그 책의 지식 스킬 전체, 필요한 지식 스킬 별칭, README·사용 가이드, 선택한 검토 요약만 배치한다. `book-to-skill-followup` 폴더·그 별칭·제작용 역할 프로필·변환기·언어 검수 vendor·원문·전체 추출물·실행 로그는 기본 배포물에 넣지 않는다. 책 지식 스킬에 필요한 독자적인 도구·자산과 제작 도구를 구분한다.

이 제한은 생성된 책 결과물에 적용한다. `book-to-skill-followup` 자체를 개발·설치·검수하는 원본 저장소에는 해당 도구와 자원이 필요하다.

## 기존 설치와 배포면

기존 로컬 제작용 설치를 찾으면 대상 지식 폴더 안인지, 프로젝트의 Git index에서 추적하는지, 명시적으로 제외됐는지 확인한다. 별칭은 정상 링크·끊어진 링크 모두 목록에 포함한다. 문서나 과거 검수 기록 안의 도구 이름 언급은 실제 설치와 구분한다.

책 지식 폴더 안에는 제작용 스킬을 중첩하지 않는다. 사용자 요청으로 책 프로젝트에 로컬 제작 도구를 설치해야 할 때도 배포에서는 제외한다. 다음은 승인된 저장소 정리에 사용할 수 있는 제외 패턴이며 자동 편집 지시가 아니다.

```gitignore
/.agents/skills/book-to-skill-followup/
/.claude/skills/book-to-skill-followup
```

이미 추적된 파일은 `.gitignore`만으로 배포에서 빠지지 않는다. 허용된 쓰기·Git 작업 범위에서 추적 해제를 반영하고 책 지식·예시·기존 검수 기록을 보존한다. 요청 없이 전역 설치를 삭제하거나 Git 이력을 재작성하거나 커밋·푸시하지 않는다. 책 프로젝트의 Git 초기화도 이 워크플로의 작업이 아니다.

## 확인과 기록

`check_package.py`는 생성된 대상에서 실제 제작용 스킬·별칭의 혼입과 Git index·제외 상태를 읽기 전용으로 검사한다. 원본 도구 자체의 검사와 생성된 책 대상의 검사를 구분한다. Git이 없으면 존재하는 로컬 제작 도구를 배포 제외됐다고 추정하지 않는다. 문서의 단순 이름 언급을 자동 삭제하지 않는다.

최종 배포 후보에서 스킬·별칭의 실제 목록, 제외된 제작물, 검사 범위와 미확인 항목을 기록한다. 아카이브를 만들면 그 실제 파일 목록도 확인하며, Git 제외만으로 임의의 폴더 복사·압축 결과를 보증하지 않는다. 생성된 책의 README·사용 예시에서 제작용 스킬의 설치나 호출을 기본 학습 조건으로 안내하지 않는다. 원문 재검수 명령에는 필요한 외부 도구·원본을 명시한다.
