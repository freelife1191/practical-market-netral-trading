# 원문 사례 색인

특정 종목으로 질문받았을 때 읽을 상세 자료와 원본 위치를 찾는 **탐색용 재구성**이다. 종목·날짜·가격·손익은 책의 당시 사례이며 현재 사실이나 재현 목표가 아니다. 표의 쪽 범위에는 설명과 도판이 함께 들어간다. 같은 페이지에서 다음 사례가 시작되면 범위가 겹친다.

4장의 번호 붙은 사례는 22개다. 로보티즈 절 안에서 함께 설명한 LG 사례를 별도 탐색 항목으로 나누어 **총 23개 항목**으로 연결했다. 이는 책에 23개의 독립 소절이 있다는 뜻이 아니다.
