# 종목 선정 상세 참고: 재료·0순위·수급을 기록으로 검증한다

**근거 범위:** 『실전 시황 트레이딩』 3장, 인쇄 67–99쪽 / PDF 63–97쪽. 본문은 PDF 65쪽부터다. PDF 66–68도 현재 추출본의 본문 텍스트와 직접 대조했다.  
**경계:** 이 파일은 저자의 선별법을 재사용 가능한 기록 양식으로 합성한 것이다. 현재 시세, 뉴스 사실, 호가, 특정 HTS의 실시간 데이터는 여기서 확인하지 않으며, 현재 매수 추천·목표가·손절률을 만들지 않는다.

## 다섯 조건 필터

아래 다섯 조건은 모두 저자의 원칙이다. 숫자 점수화는 새 적용 양식이며, ‘통과 수가 많으면 매수’라는 규칙은 아니다.

| 주도 섹터/테마 | 지금 시장의 돈이 이 묶음으로 흐른다는 관찰이 있는가? | 종목만 오르고 묶음·관심·자금 흐름을 설명하지 못함 | PDF 66 |

**예외를 보존한다:** 저자는 얇은 호가의 테마주를 무조건 피하라고 하지 않는다. 다만 자금이 커질수록 체결이 어려워질 수 있으므로 자금 규모에 맞춰 유연하게 판단하라고 한다(인쇄 69쪽 / PDF 67쪽). 따라서 호가 두께는 방향 예측 지표가 아니라 실행 가능성 점검이다.

## 재료 필터: 소음을 영향도와 연속성으로 바꾼다

저자는 뉴스가 뜨자마자 매수하는 속도전보다 ‘국내 증시에 얼마나 큰 영향을 줄 것인가’를 먼저 보라고 한다(인쇄 70쪽 / PDF 68쪽). 주도 섹터가 선행하고, 그 안의 대장·관련주의 반응과 후속 일정이 뒤따른다. 원문은 실적, 계약 수주, 정책 발표, 신제품 출시, 인수합병, 임상 결과를 강한 재료가 될 수 있는 예로 든다(인쇄 74–78쪽 / PDF 72–76쪽). 이는 분류 예시일 뿐 사건이 곧 가격 상승을 뜻하지 않는다.

### 재료 검증표

| 확인 항목 | 질문 | 기록 방식 |
| --- | --- | --- |
| 출처·시점 | 1차 공시/발표인가, 보도인가? 언제 나왔는가? | URL 또는 문서명과 시각. 확인하지 못했으면 `확인 불가` |
| 영향 범위 | 한 기업, 관련 종목, 섹터, 지수 중 어디에 영향을 줄 논리인가? | ‘연결 고리’를 한 문장으로 작성 |
| 다음 날 거래대금 | 다음 거래일에도 거래대금이 유지되는가? | 같은 기준 시점의 관찰값과 변화 방향 |
| 대장 추세 | 대장 후보가 흐름을 지키는가? | 가격 방향만이 아니라 거래대금·동반 움직임 함께 기록 |
| 관련주 동반 | 비슷한 성격의 종목이 함께 움직이는가? | 종목명 나열보다 공통 재료와 반응 차이 기록 |
| 후속성 | 공식 일정·후속 발표가 남아 있는가? | 확인 가능한 일정만 기록, 추측은 `미확인` |
| 선반영 | 이미 과도하게 반영됐는가? | 사실 판단이 어려우면 확정하지 않고 경계 가설로 남김 |

### 실패 패턴

- 모든 뉴스와 모든 산업군을 같은 깊이로 읽어 현재의 주도 흐름을 놓친다.
- 첫날 움직임을 놓친 뒤 ‘강한 재료니까’라는 말로 추격을 합리화한다.
- 기사 수나 검색량을 영향도의 대용물로 쓰고, 대장·동반 종목·거래대금의 후속 반응을 보지 않는다.
- 과거 사례의 종목명·성과를 현재성 검증 없이 재료로 재활용한다.

### 시장을 움직이는 키워드부터 좁히기

저자는 주도 흐름을 좌우하는 인물·사건을 하나의 키워드로 정하고, 관련 뉴스·일정을 깊게 확인하는 방법을 설명한다(인쇄 70–72쪽 / PDF 68–70쪽). 당시 트럼프 관련 뉴스는 그 방법의 개인 사례이며 현재의 고정 검색어나 시장 전망이 아니다. 작성자 양식은 `영향 인물/사건 → 확인할 뉴스·일정 → 긍정/부정 영향 → 실제 가격·거래대금 반응`으로 기록한다. 명확한 주도 섹터가 없을 때는 강한 개별 재료 탐색 갈래를 함께 둔다(인쇄 74쪽 / PDF 72쪽).

## 0순위 후보 기록표

저자는 `2-2-2`로 정리한 관심 종목에서 전일 관심도, 거래대금·변동성, 관련 종목 동반 움직임, 재료 연속성, 신고가 또는 의미 있는 가격, 다음 날 시나리오를 보며 통상 한두 종목을 0순위로 둔다(인쇄 79–81쪽 / PDF 77–79쪽). 가격에서는 저자가 **250일 신고가를 앞두거나 이미 신고가 흐름인 종목**에 더 높은 우선순위를 둔다(인쇄 80쪽 / PDF 78쪽). 전일 관심은 저자의 경우 조회 순위 1–10위 안에서 강했던 종목을 기준으로 한다(인쇄 81쪽 / PDF 79쪽). 0순위는 관찰 우선순위이며, 장중 이슈 유지나 매수 결과를 보장하지 않는다.

| 항목 | 기록 | 판정 |
| --- | --- | --- |
| 전일 시장 관심 | 실시간 조회 누적 순위 또는 동등한 관찰 근거 | 충족 / 불명확 / 미충족 |
| 거래대금·변동성 | 전일과 당일의 비교 기준·시간 | 충족 / 불명확 / 미충족 |
| 동반 움직임 | 같은 재료·섹터의 종목이 어떻게 반응했는가 | 충족 / 불명확 / 미충족 |
| 재료 연속성 | 남은 일정·후속 뉴스·대장 추세 | 충족 / 불명확 / 미충족 |
| 의미 있는 가격 | 신고가·전고점·라운드 피겨 등과 이유 | 관찰만 / 전제 훼손 / 확인 불가 |
| 다음 날 계획 | 관찰 지속 신호, 무효 신호, 차순위 교체 조건 | 문장으로 작성 |
| 저자의 명시 제외 | 다음 날 조회 순위가 10위권 밖, 또는 15분봉 120일 이동평균선을 깨고 회복하지 못함 | 저자의 개인 관심 종목 기준으로만 표기 |

**교체·제외 규칙:** 저자는 거래대금이 빠지거나 힘이 예상보다 약하면 0순위에 집착하지 않고 다음 후보를 보라고 한다(인쇄 80–81쪽 / PDF 78–79쪽). 또한 다음 날 조회 순위가 10위권 밖으로 이탈하거나 15분봉 120일 이동평균선을 깨고 회복하지 못하면 관심 종목에서 제외한다(인쇄 81–82쪽 / PDF 79–80쪽). 이 두 수치는 저자의 개인 화면·판정 기준이므로 자동 매도 명령이나 일반 공식으로 바꾸지 않는다. 아래 차순위·교체 칸은 이를 기록하기 위한 새 적용 양식이다.

## 수급주: 외국인·기관을 결과가 아니라 흐름으로 본다

저자는 수급을 수요와 공급, 즉 돈의 흐름으로 설명하고 기관·외국인 등 큰 자금이 집중되는 종목을 수급주 맥락에서 다룬다(인쇄 85쪽 / PDF 83쪽). 수급주를 찾는 저자의 네 조건은 (1) 큰 거래대금, (2) 시장을 이끄는 주도 섹터, (3) 프로그램·외국인·기관 같은 큰 자금 유입, (4) 신고가나 추세 돌파처럼 강한 차트 흐름이다(인쇄 86–87쪽 / PDF 84–85쪽). 호가창 두께는 일반 종목 5조건 및 테마주·수급주 비교에서 나오는 실행 가능성·유형 비교 요소이며, 이 네 조건의 넷째 항목이 아니다. 여기서 수급 정보는 시황·주도 섹터·거래대금·변동성이 확인된 뒤의 보조 확인이며, 거래대금·변동성이 없는 종목에서 외국인·기관의 소량 매수만으로 큰 의미를 두지 말라고 한다(인쇄 89쪽 / PDF 87쪽).

### 외국인·기관 체크 순서

1. 먼저 시황·주도 섹터·재료·거래대금·변동성이 있는지 확인한다.
2. 외국인과 기관의 당일 방향을 본다. 저자는 **금액보다 수량**을 보며 복잡한 누적 계산 대신 당일 방향을 매일 확인한다고 설명한다(인쇄 92쪽 / PDF 90쪽). 아래와 같은 새 기록 양식에서 다른 단위를 쓰면 단위·조회 시점과 작성자 선택을 표시하고 저자의 방식과 구분한다.
3. 하루 매수보다 며칠·여러 관찰 시점의 **연속성**을 적는다.
4. 두 주체가 함께 순매수하는 양매수는 저자가 선호하는 관찰 신호지만, 매수 명령으로 바꾸지 않는다(인쇄 92쪽 / PDF 90쪽).
5. 가격·거래대금이 수급 방향과 어긋나면 ‘수급이 좋다’고 결론 내리지 않고 추가 관찰로 둔다.

| 오해 | 원문에 맞춘 수정 |
| --- | --- |
| 외국인이 하루 샀으니 수급주다 | 저자는 연속성 있는 외국인·기관 매수세를 중요하게 본다(인쇄 92쪽 / PDF 90쪽). |
| 기관이 사면 무조건 장기 상승한다 | 기관·외국인 성향에 관한 저자의 관찰은 100% 정답이 아니라고 명시한다(인쇄 88쪽 / PDF 86쪽). |
| 테마주와 수급주는 완전히 분리된다 | 저자는 전형을 대비하지만, 시장 관심·거래대금·변동성이 공통 출발점이다(인쇄 86–89쪽 / PDF 84–87쪽). |

## 프로그램 매매와 거래원: 주체 확인의 보조 자료

### 프로그램 매매

저자는 프로그램 매매를 정해진 값·조건에 따라 자동 주문을 내는 시스템으로 설명하며, 전일 종가·전일 고가 같은 의미 있는 자리에서의 흐름을 본다(인쇄 93쪽 / PDF 91쪽). 프로그램은 원웨이 매수·매도, 장중 단기 매매처럼 다르게 나타날 수 있고, 특히 중소형주에서는 매수 물량만큼 빠른 매도가 나와 변동성이 강해질 수 있다고 말한다(인쇄 93–97쪽 / PDF 91–95쪽).

**기록 규칙:** `가격 자리 → 프로그램 순매수/순매도 변화 → 거래대금·가격 반응 → 지속/반전` 순으로 적는다. 프로그램 수치 하나로 시장 방향을 고정하지 않는다. 저자가 든 유가·미국 반도체 사례는 당시 시황 변수가 알고리즘 반응에 영향을 줄 수 있음을 설명하는 사례이며, 현재 트리거 목록이 아니다(인쇄 98쪽 / PDF 96쪽).

### 거래원

저자는 거래원 분석으로 어느 증권사 창구가 많이 사고파는지 살펴볼 수 있다고 한다(인쇄 98–99쪽 / PDF 96–97쪽). 그러나 창구 성향은 그 창구를 이용한 특정 주체의 패턴일 뿐이고, 특정 증권사와 패턴을 고정 매칭해 적용하지 말라고 명시한다. 알고리즘 주문도 여러 창구에서 일어날 수 있다(인쇄 99쪽 / PDF 97쪽).

**화면번호 원문 불일치:** 본문은 `[0218] 거래원입체분석`이라 적지만(인쇄 98쪽 / PDF 96쪽), 이어지는 화면 캡션은 `[0128] 거래원입체분석`으로 표시한다(인쇄 99쪽 / PDF 97쪽). 제공 PDF 내부의 불일치이므로 특정 화면번호를 기록 양식의 필수 조건으로 삼지 않는다.

**기록 규칙:** 당일 매매 대상에서 주도 매수·매도 창구와 프로그램 흐름의 관계를 관찰 메모로 남긴다. ‘A 창구 = 상승’ 같은 정적 규칙은 만들지 않는다.

## 원문 사례 재구성: 재료의 첫날을 놓쳤을 때

저자는 강한 재료의 종목을 첫날 놓쳤더라도, 진짜 강한 재료라면 이후에도 거래대금·변동성이 생겨 자신에게 맞는 자리가 다시 올 수 있다고 설명한다(인쇄 72–73쪽 / PDF 70–71쪽). 이를 기록 양식으로 바꾸면 다음과 같다.

| 상황 | 즉시 결론 | 다음 관찰 |
| --- | --- | --- |
| 첫 반응을 놓침 | 추격하거나 기회를 잃었다고 단정하지 않음 | 다음 날 거래대금 유지와 대장 추세 |
| 관련주가 움직임 | 모두 같은 강도라고 가정하지 않음 | 공통 재료, 동반성, 각 종목의 관심·유동성 |
| 후속 일정이 있음 | 일정만으로 가격을 예측하지 않음 | 시장이 이미 반영했는지와 실제 반응 |
| 수급이 보임 | 단일 주체·단일 시점으로 확정하지 않음 | 외국인·기관·프로그램 흐름의 연속성 |
