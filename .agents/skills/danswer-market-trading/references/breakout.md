# 돌파매매: 중요한 가격을 넘는 ‘힘’을 거래하는 법

## 참고 범위와 사용 한계

- **참고 범위:** 『실전 시황 트레이딩』 4장 「돌파매매: 장중매매의 꽃」, 인쇄 144–165쪽. 원문 대조 범위는 PDF 141–162쪽이다.
- **정의:** 이전에 여러 번 막힌 저항선·매물대 또는 다수가 보는 중요한 가격을 강한 거래대금과 매수세로 넘어설 때 진입해, 돌파 뒤의 추가 상승을 노리는 장중 매매다(인쇄 144–145쪽 / PDF 141–142쪽).
- 원문은 장중 관찰과 빠른 철회를 전제한다. 호가·거래대금·순위 변화와 손절을 실시간으로 확인할 수 없다면 이 방식의 핵심 조건이 빠진다. 이 문서는 현재 종목 추천, 고정 비중, 수익 보장이 아니다.

## 돌파는 선을 넘은 사실이 아니라 매물을 이긴 과정이다

전고점·당일 고점·라운드 피겨를 잠깐 웃도는 것만으로 매수하지 않는다(인쇄 145–146쪽 / PDF 142–143쪽). 같은 가격에서 반복해 막혔던 매도 물량을 새 매수세가 소화하고, 거래량·거래대금이 증가하며, 그 가격 위에서 지지되는지를 봐야 한다(인쇄 144–146쪽 / PDF 141–143쪽). 관심 없는 종목은 누군가가 가격을 잠시 올려도 뒤에서 받아 줄 매수자가 부족해 다시 밀릴 수 있다(인쇄 148쪽 / PDF 145쪽). 반대로 주도주는 개인·기관·외국인·프로그램 등 더 많은 참여자가 보므로 돌파 뒤 연속성이 생길 여지가 있다(인쇄 149쪽 / PDF 146쪽).

**조건 → 판단 → 실행 → 철회**로 바꾸면 다음과 같다.

1. 실시간 조회 상위권, 충분한 거래대금, 섹터·테마 동반 움직임 또는 강한 개별 재료가 있는 주도주만 후보로 둔다(인쇄 164쪽 / PDF 161쪽).
2. 전일 종가·전일 고가·당일 시가·당일 고가·단기/250일 신고가·라운드 피겨 중 시장 참여자가 함께 볼 가격을 하나 정한다. 두꺼운 호가의 ‘덩어리 물량’이 실제로 소화되는지 확인한다(인쇄 150쪽 / PDF 147쪽).
3. 돌파 직전 거래량·거래대금과 매수세가 늘고, 같은 가격을 여러 번 건드리며 지수보다 상대적으로 강하면 진입한다(인쇄 164–165쪽 / PDF 161–162쪽). 저자는 돌파 후 지지까지 보고 재돌파에 들어가는 사례도 제시한다(인쇄 158쪽 / PDF 155쪽).
4. 매수 근거인 가격을 지키지 못하거나(인쇄 152쪽 / PDF 149쪽) 계획과 다른 수급이 나오면 청산한다(인쇄 163쪽 / PDF 160쪽). 저자의 손절 기준은 **매수가에서 주로 2% 이내**이며, 이는 원문의 개인 실행 기준이다(인쇄 152쪽 / PDF 149쪽). 고정 손절률로 일반화하지 말고 가격 무효화와 개인 위험 한도를 함께 정해야 한다.

## 종가 베팅과의 차이

둘 다 관심·주도주·거래대금·재료·수급이 있는 강한 종목을 산다(인쇄 147쪽 / PDF 144쪽). 차이는 검증할 시간과 기대 수익의 창이다(인쇄 147쪽 / PDF 144쪽). 돌파매매는 중요한 가격을 넘기 직전 또는 그 순간, 초·분 단위 매수세를 확인하고 당일 추가 상승을 기대한다(인쇄 147쪽 / PDF 144쪽). 종가 베팅은 정규장 또는 애프터 마감 부근에서 하루의 강함이 다음 날에도 이어질지 판단한다(인쇄 147쪽 / PDF 144쪽). 저자는 전일 고가 돌파로 수익이 난 종목이 신고가까지 돌파하면 종가 베팅으로 끌고 가기도 하고, 신고가 영역에서 한 번 매도한 뒤 근거가 있을 때 재진입하기도 한다(인쇄 152쪽 / PDF 149쪽). 전환은 자동이 아니라 마감까지 매수 근거가 살아 있다는 재확인이 필요하다.

## 장중 준비 루틴과 시소 매매

돌파는 장전 준비가 늦으면 따라잡기 쉽다(인쇄 153–154쪽 / PDF 150–151쪽). 원문의 개인 루틴은 전날 오후 2시·오후 8시 당일 누적 조회 순위에서 **섹터 2개, 테마 2개, 개별주 2개**를 골라 관심종목 여섯 개를 만들고(인쇄 153쪽 / PDF 150쪽), 각 종목의 전일 종가·전일 고가·라운드 피겨·250일 신고가·단기 신고가를 미리 표시하는 것이다(인쇄 154쪽 / PDF 151쪽). 숫자 여섯 종목 자체가 보편 규칙이라기보다, 장중 가격을 새로 찾지 않기 위한 저자의 작업량 설정이다.

밤사이 미국 증시를 확인해 오전 공략 여부를 정하고(인쇄 155쪽 / PDF 152쪽), 정규장 **09:00–09:10**의 극심한 변동성 구간은 피한다(인쇄 165쪽 / PDF 162쪽). 본문 다른 설명에는 10–15분 뒤부터 시작한다는 저자의 습관도 있다(인쇄 152쪽 / PDF 149쪽). 이 시간은 고정 진입 시각이 아니라 개장 소음이 가라앉고 가격·순위 변화를 볼 때까지 기다리라는 제약으로 해석한다.

장중에는 조회 순위를 30초로 전환한다(인쇄 150쪽 / PDF 147쪽). 예컨대 반도체 상위 종목이 고가 돌파에 실패하며 관심·매수세가 빠지고, 전고점 앞에서 횡보하던 로봇주가 순위를 올리며 매수 속도가 빨라진다면 ‘막힌 돈’이 새 후보로 이동하는 시소 매매 가설을 세울 수 있다(인쇄 150–152쪽 / PDF 147–149쪽). 단, 순위 상승만으로 매수하지 말고 그 후보가 미리 정한 가격을 돌파할 힘과 지지를 보이는지로 다시 걸러야 한다.

## 종목 유형마다 다른 확인점

- **섹터주:** 외국인·기관 수급(인쇄 156쪽 / PDF 153쪽)과 지수 흐름을 함께 본다. 섹터 전체에 큰 돈이 들어오는지가 핵심이다(인쇄 156쪽 / PDF 153쪽).
- **테마주:** 개인 매매 성향이 강해 기관·외국인 수급이 없어도 강할 수 있다(인쇄 156쪽 / PDF 153쪽). 같은 테마 종목의 동반 움직임(인쇄 164쪽 / PDF 161쪽)·재료 지속성(인쇄 167쪽 / PDF 164쪽)을 본다.
- **개별주:** 시장 전체 수급보다 해당 종목의 외국인·기관·개인 수급(인쇄 156쪽 / PDF 153쪽)과 뉴스 반응(인쇄 164쪽 / PDF 161쪽)을 본다. 누가 큰손이 될지는 확정할 수 없으므로(인쇄 156쪽 / PDF 153쪽), 추정이 아니라 실제 체결·가격 유지로 판단을 갱신한다.

## 진입·청산 계획

원문에서 저자는 중요한 가격대의 첫 진입에 최소 50% 이상, 계획이 완벽하다고 볼 때 70%까지 비중을 싣고 상승 확인 뒤 나머지를 더하는 불타기를 설명한다(인쇄 152쪽 / PDF 149쪽). 이는 저자의 개인 설정이며, 이 참고자료의 권장 비중이 아니다. 특히 손절·재진입을 즉시 실행할 수 없는 환경에는 적용 근거가 없다.

익절은 다음 의미 있는 가격에 둔다(인쇄 152쪽 / PDF 149쪽). 전일 종가 돌파로 들어갔다면 전일 고가를 다음 목표로 보고, 전일 고가를 넘은 뒤 신고가까지 힘이 이어질 때만 종가 보유 가능성을 다시 판단한다(인쇄 152쪽 / PDF 149쪽). 가격이 매수가 아래로 밀려 근거가 사라졌거나(인쇄 152쪽 / PDF 149쪽) 대규모 매도 물량처럼 전제가 바뀌면 ‘기다리면 회복’이라는 기대를 철회한다(인쇄 163쪽 / PDF 160쪽). 이것이 실패 대응이다.

**다음 날을 넘기는 경우의 처리:** 돌파의 목적은 원칙적으로 당일 추가 상승이다(인쇄 147쪽 / PDF 144쪽). 종가 베팅으로 바꾸는 것은 신고가까지 힘이 이어지고 마감까지 근거가 살아 있을 때의 별도 판단이다. 그렇게 보유를 넘겼다면 다음 날 갭과 밤사이 위험은 돌파 규칙만으로 관리할 수 없으며, 종가 베팅의 세션·유동성·손절 계획을 새로 적용한다. 이 절의 원문은 다음 날의 고정 청산 시각이나 손절률을 제시하지 않으므로 임의 수치를 덧붙이지 않는다.

## 원문 매매일지의 판단 흐름 재구성

**LIG 디펜스앤에어로스페이스 사례.** 전날 애프터의 비공개 계약 공시 뒤 신고가를 넘은 종목에서, 저자는 100만 원 라운드 피겨를 주목했다(인쇄 158쪽 / PDF 155쪽). 정규장에서 가격을 넘은 뒤 즉시 추격하지 않고 해당 가격에서 크게 밀리지 않는 지지를 확인한 후 재돌파에 진입했다(인쇄 158쪽 / PDF 155쪽). 다음 의미 가격인 110만 원 부근에서 남은 물량을 정리했다(인쇄 158쪽 / PDF 155쪽). 교훈은 ‘돌파 캔들’이 아니라 **재료·신고가·라운드 피겨·지지 확인·다음 목표**를 한 계획으로 연결하는 데 있다.

**두산로보틱스 사례.** 개장 뒤 이 종목은 조회 순위 5–6위에서 횡보했고, 위 순위의 반도체 종목이 주춤거리자 매수 속도가 빨라졌다(인쇄 158–159쪽 / PDF 155–156쪽). 저자는 전일 종가 위라는 전제와 당일 고가 돌파 기대를 결합해 진입하고, 고가 돌파 뒤 분할 매도로 마무리했다(인쇄 159쪽 / PDF 156쪽). 이는 30초 순위가 단독 신호가 아니라, 돈의 이동과 미리 정한 가격대가 일치할 때만 쓰인다는 사례다.

**매드업 사례.** 지수를 이끌던 삼성전자가 전일 종가를 깨고 하락하려 하자 최근 상장한 신규주로 돈이 옮겨가는 흐름을 확인했다(인쇄 161–162쪽 / PDF 158–159쪽). 저자는 매드업이 약 9,250원에서 주춤한 뒤 당일 고가를 다시 돌파할 때 진입했다(인쇄 161–162쪽 / PDF 158–159쪽). 신규주를 지수 하락의 헤지로 보는 것은 원문이 전하는 당시 시장의 인식이며(인쇄 161쪽 / PDF 158쪽) 모든 신규주의 역상관을 뜻하지 않는다. 본문이 구체적인 청산 가격·시간을 정하지 않으므로 새로 만들지 않는다.

**현대오토에버 사례(실패 전환).** 저자는 56만 원·57만 원·58만 원 세 구간에서 돌파로 진입해 강한 흐름을 종가 베팅으로 넘기려 했다(인쇄 163쪽 / PDF 160쪽). 그러나 상한가가 풀리고 **1,000억 원을 훨씬 넘는 매도 물량**이 나오자 보유 근거가 사라져 계획을 폐기했다(인쇄 163쪽 / PDF 160쪽). 이 세 가격대와 매도 물량은 원문 본문에 명시된 개인 사례의 수치다(인쇄 163쪽 / PDF 160쪽). 불확실한 것은 대체거래소에서 여러 번 매매한 탓에 실현손익 화면의 평균 매입가가 정확히 표현되지 않는 듯하다는 저자의 설명에만 한정한다(인쇄 163쪽 / PDF 160쪽). ‘상한가 유지’라는 전제가 깨졌을 때 바로 철회한 판단을 보존한다.

### HD현대에너지솔루션: 최초 가설 철회와 새 흐름 재진입

저자는 태양광 분위기, 신성이엔지 거래 재개와 한화솔루션 유상증자 연기 재료를 보고 전날부터 소액 분할로 접근했다(인쇄 159–160쪽 / PDF 156–157쪽). 다음 날 갭이 예상보다 약하고 쉽게 오르지 않자 전량 매도했다(인쇄 160쪽 / PDF 157쪽). 이후 매수 속도가 다시 빨라지자 22만 원·22만 5,000원·23만 원 같은 의미 있는 가격에서 다시 진입하며 비중을 늘렸고, 24만 4,000원 신고가까지 분할 매도 계획을 세워 실행했다(인쇄 159–161쪽 / PDF 156–158쪽). 핵심은 **약한 최초 흐름의 철회 → 새로 확인한 속도·가격에 따른 재진입**이다(인쇄 161쪽 / PDF 158쪽). 가격·금액·도판 날짜를 현재 거래의 확정값으로 옮기지 않는다.

## 실무 체크리스트

원문은 **주도주·돌파 가격·돌파 힘·타이밍의 네 묶음을 모두 충족할 때 매매한다**고 설명한다(인쇄 164–165쪽 / PDF 161–162쪽). 아래는 이를 재배열한 점검표이며, 일부 항목만 통과한 것을 진입 확정으로 바꾸지 않는다.

- [ ] 주도주인가: 실시간 조회 상위권, 충분한 당일 거래대금, 섹터·테마 핵심성/동반 움직임 또는 시장이 반응하는 재료가 있는가(인쇄 164쪽 / PDF 161쪽)?
- [ ] 가격이 명확한가: 전일 종가·전일 고가·라운드 피겨·단기 신고가·250일 신고가 중 하나를 모두가 보는가(인쇄 164쪽 / PDF 161쪽)?
- [ ] 힘이 있는가: 돌파 전 거래량·거래대금·매수세가 증가하고, 반복 접촉으로 매물을 소화하며, 지수보다 강한가(인쇄 164–165쪽 / PDF 161–162쪽)?
- [ ] 타이밍이 맞는가: 개장 직후 극심한 변동성을 피했고, 이미 급등 뒤늦은 추격이 아니며, 더 강한 종목으로 관심이 이동하지 않았는가(인쇄 165쪽 / PDF 162쪽)? 손절가와 다음 의미 가격을 비교할 때 손익비가 충분한가(인쇄 165쪽 / PDF 162쪽)? 원문에 없는 고정 손익비 수치를 만들지 않는다.
- [ ] 청산이 정해졌는가: 무효화 가격, 다음 의미 가격의 익절 계획(인쇄 165쪽 / PDF 162쪽), 장중 관찰 불가 시 주문·대응 한계를 적었는가?
