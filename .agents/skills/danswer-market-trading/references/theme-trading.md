# 테마주·짝꿍 매매

## 원문 범위와 용도

이 자료는 『실전 시황 트레이딩』 PDF 163~180쪽(인쇄 166~183쪽)의 테마주 매매를 정리한 것이다. 저자의 단기 트레이딩 규칙을 학습·복기하는 참고자료이며, 과거 종목이나 성과를 현재의 매수 추천으로 바꾸지 않는다. 테마주는 뉴스·정책·인물·사건이라는 하나의 이슈로 묶인 종목에 단기 자금이 몰리는 현상이다(인쇄 166–167쪽 / PDF 163–164쪽). 산업·실적·수주와 외국인·기관 수급을 중심으로 며칠간 순환할 수 있는 섹터주와 달리, 재료가 소멸하면 반등 없이 크게 밀릴 수 있으므로 기대감의 지속성, 대장주, 시장 관심도를 매 순간 다시 확인한다(인쇄 167쪽 / PDF 164쪽).

## 저자 규칙: 좋은 재료와 배제 조건

좋은 테마는 처음 터진 신선한 이슈, 전 세계 헤드라인이 될 정도의 파급력, 뒤따라 이어질 재료를 함께 갖춘 경우다(인쇄 170쪽 / PDF 167쪽). 코로나에서 마스크·진단키트·재택근무로, 전쟁에서 곡물·비료·에너지·재건으로 재료가 연결된 예가 원문에 있다(인쇄 170쪽 / PDF 167쪽). 반대로 계절마다 예고되고 반복돼 이미 모두가 아는 테마는 신선함이 약해 대체로 피한다(인쇄 171쪽 / PDF 168쪽). 정치 테마는 반복처럼 보여도 후보와 정책이 바뀌므로 저자가 예외로 든다(인쇄 171쪽 / PDF 168쪽).

테마주는 얇은 호가와 빠른 회전이 장점이지만, 손절 때 스스로 여러 호가를 밀 수 있는 것이 핵심 위험이다(인쇄 168쪽 / PDF 165쪽). 따라서 큰 자금을 억지로 넣거나(인쇄 168쪽 / PDF 165쪽), 재료·관심도·대장 흐름을 설명하지 못하거나(인쇄 167쪽 / PDF 164쪽), 시장이 관심을 주지 않아 동류 종목이 동반 변동하지 않는 경우는 배제한다(인쇄 183쪽 / PDF 180쪽). 저자는 빠른 판단 능력과 충분한 사전 학습·준비를 필요 조건으로 들며, 비교적 젊고 주식 성공이 간절한 사람에게 도전하라고 권하는 개인적 견해도 덧붙인다(인쇄 169쪽 / PDF 166쪽). 소액일 때 변동성을 활용할 수 있다는 저자의 맥락을 고액 운용의 권유로 확대하지 않는다.

## 저자 규칙: 대장·후속주와 짝꿍

여기서 **거래대금 대장**과 **테마 속도 대장**을 혼동하지 않는다. 저자는 테마주에서는 종가 베팅·돌파 매매와 달리 거래대금 자체보다, 테마 안에서 가장 빠르게 상한가에 진입하고 등락률이 가장 높은 종목을 대장으로 본다(인쇄 171쪽 / PDF 168쪽). 거래대금이 동반되면 대장도 끌고 갈 수 있으나, 동반 거래대금 없이 상승률만 치솟는 경우에는 대장 대신 2·3등 후속주를 보는 짝꿍 매매를 설명한다(인쇄 171쪽 / PDF 168쪽).

대장이 상한가에 걸리면 그 종목을 사려던 매수세가 후속주로, 2등주까지 상한가가 되면 3등주로 이동할 수 있다는 순환 논리다(인쇄 171–172쪽 / PDF 168–169쪽). 후속주의 진입 후보는 대장 흐름을 먼저 확인한 뒤에만 검토한다(인쇄 171쪽 / PDF 168쪽). 원문 표의 중요도는 상한가 진입 순간(★★★★★), 대장이 2차 VI에 진입하는 순간(대략 25% 이상 상승, ★★★★☆), 대장이 10% 이상 하락 뒤 강한 반등으로 VI에 재진입하는 순간(★★☆☆☆), 1차 VI 진입 순간(보통 12% 이내, ★☆☆☆☆) 순이다(인쇄 172쪽 / PDF 169쪽). 이는 저자의 경험상 우선순위이며 자동 매수 신호가 아니다.

## 저자 규칙: 진입·손절·청산 절차

1. 실시간 조회에서 유사 성격 종목이 함께 떠오르고 후속주도 기본 10% 이상 변동하는지, 체결 속도가 빠른지 확인한다(인쇄 183쪽 / PDF 180쪽). 대장과 재료를 모르면 관찰만 한다.
2. 대장의 상한가 직전·2차 VI 같은 높은 우선순위 구간에서 후속주를 검토한다(인쇄 183쪽 / PDF 180쪽). 저자는 대장이 2차 VI·상한가에 들어가기 약 10호가 전 또는 당일 고가 약 10호가 전에서 미리 진입하는 방식을 든다(인쇄 173쪽 / PDF 170쪽).
3. 비중은 자신의 시드와 매수 호가의 소화 가능성을 함께 보고, 손절 시 3개 호가 이상을 밀지 않을 양으로 정한다(인쇄 173쪽 / PDF 170쪽). 예시는 0·1·2호가 매수잔량 합계가 3,300만 원일 때 한 번의 매수를 그보다 크게 하지 않는 방식이다(인쇄 173쪽 / PDF 170쪽).
4. 손절 퍼센트를 미리 고정하지 않는다(인쇄 174쪽 / PDF 171쪽). 대장이 의미 있는 가격에 도달한 뒤에도 주춤거리거나 내려가면 즉시 매도한다(인쇄 173–174쪽 / PDF 170–171쪽). 후속주가 아니라 **대장의 속도와 멈칫함**이 손절 기준이다(인쇄 174쪽 / PDF 171쪽).
5. 예상대로 계속 치면 후속주를 들되, **후속주 자체가 상한가에 들어가면** 최대 10분을 넘기지 않고 매도한다(인쇄 174쪽 / PDF 171쪽). 평범한 테마에서는 **대장주가 상한가에 들어간 뒤** 후속주를 보통 1~2분 더 보고 매도한다(인쇄 174쪽 / PDF 171쪽). 다만 2·3·4등주까지 10% 이상 변동성이 유지되는 강한 테마에서는 저자가 2·3등주를 상한가까지 보유하기도 했다(인쇄 174쪽 / PDF 171쪽). 다음 날 보유를 일반 규칙으로 제시하지 않았으므로, 이 자료도 별도 원칙을 만들지 않는다.

## 훈련과 시황·섹터 연계

매일 장 마감 뒤 특징주와 상승 이유를 복기해 종목·연결 테마를 외운다(인쇄 174–175쪽 / PDF 171–172쪽). 새 이슈가 나왔을 때 대장 후보와 짝꿍 후보를 빠르게 떠올리기 위한 훈련이다(인쇄 175쪽 / PDF 172쪽). 원문의 QR 영상은 저자의 과거 소액 짝꿍 매매 영상·쇼츠가 남아 있다는 안내만 제공한다(인쇄 175쪽 / PDF 172쪽). 영상 자체는 확인하지 않았으며 그 내용을 추정하지 않는다.

강한 테마가 시장에서 검증되면 동일 테마의 다른 매매 기회까지 넓게 볼 수 있다는 것이 저자의 확장 원리다(인쇄 181쪽 / PDF 178쪽). 이는 테마주를 섹터주로 바꾸어 해석하라는 뜻은 아니다. 업황·실적·기관·외국인 수급의 지속을 읽는 섹터 매매는 [종목 선별](stock-selection.md)과 [패턴](../patterns.md)에서 별도로 점검한다.

## 원문 사례 재구성

- **누보(2023-04-21)**: 흑해곡물협정 연장 중단 가능성으로 곡물·비료·농업 테마가 움직였고, 저자는 누보를 대장으로, 한일사료·효성오앤비·아세아텍을 후속으로 서술한다(인쇄 176–177쪽 / PDF 173–174쪽). 시가 갭, VI, 재차 갭 뒤 상한가로 향하는 대장의 속도를 근거로 당일 매수했고, 다음 날 상한가 바로 아래 시초 흐름에서 매도했다(인쇄 177쪽 / PDF 174쪽). 원문 속 미수 사용과 수익은 당시 개인 사례이지 재현 가능한 전략이나 권유가 아니다.
- **상보(2023-09-12)**: 크리스탈신소재의 그래핀 관련 뉴스 후, 저자는 대장이 3,000원 매물대를 돌파해 2차 VI로 가는지를 보면서 후속주 상보를 매매했다(인쇄 178–179쪽 / PDF 175–176쪽). 핵심은 후속주 자체의 독립 신호가 아니라 대장의 강한 속도 확인과 사전에 익힌 테마 연결이다(인쇄 178–179쪽 / PDF 175–176쪽).
- **로보티즈·LG(2026-06-01~02)**: 저자는 젠슨 황 방한 관련 로봇 테마에서 로보스타가 정규장 상한가에서 풀려 보합까지 밀린 뒤 대체거래소에서 다시 상한가에 들어가는 흐름으로 테마의 힘을 읽고 로보티즈를 매매했다(인쇄 180–181쪽 / PDF 177–178쪽). 이어 테마가 검증됐다고 보고 같은 로봇 테마의 LG그룹 종목 LG를 시가에 매매했다(인쇄 180–182쪽 / PDF 177–179쪽). 첫 상한가만이 아니라 이탈 뒤 재강화와 거래 세션의 차이가 판단 근거였던 사례다(인쇄 181쪽 / PDF 178쪽). 같은 뉴스·종목을 현재 매수하라는 근거가 아니다.

## 실행 전 체크리스트와 흔한 오판

- [ ] 처음 터진 이슈이며, 세계적 파급력과 재료의 연속성을 설명할 수 있는가? (인쇄 183쪽 / PDF 180쪽)
- [ ] 30초 조회에서 유사 종목 여러 개가 함께 올라오고, 대장과 후속주의 체결 속도·변동성이 유지되는가? (인쇄 183쪽 / PDF 180쪽)
- [ ] 거래대금이 큰 종목을 기계적으로 테마 대장이라고 부르지 않았는가? 테마 대장은 속도·등락률로 따로 판정했는가? (인쇄 171쪽 / PDF 168쪽)
- [ ] 후속주 진입이 대장 확인 뒤이며(인쇄 171쪽 / PDF 168쪽), 3개 호가 안에서 청산 가능한 비중인가? (인쇄 183쪽 / PDF 180쪽)
- [ ] 대장 멈칫 때 즉시 정리할 준비가 되어 있으며(인쇄 183쪽 / PDF 180쪽), 상한가 뒤 시간을 끌 이유를 새로 만들지 않는가? (인쇄 174쪽 / PDF 171쪽)

오판은 반복·예고 테마를 신선한 재료로, 후속주의 일시 반등을 대장 강세로, 한 종목의 급등을 테마 전체의 힘으로 오인하는 데서 나온다. 얇은 호가에서는 손절 자체가 가격을 더 밀 수 있으므로 체결 가능성을 먼저 계산한다(인쇄 173쪽 / PDF 170쪽).
