# 출처·쪽 대응·목차 포함 범위

원문의 판단 구조를 합성한 프로젝트 자료다. 저자의 직접 원칙, 사례 재구성, 추가 적용 양식은 각 파일에서 구별한다. 이 표는 원문 복제와 완전한 전수 숫자 판독을 뜻하지 않는다.

## 원본과 쪽 규약

- 저자: 이진호(디앤서), 제목: 『실전 시황 트레이딩』.
- PDF는 299쪽. 실제 본문은 7장이며 추출기의 숫자 기반 42장 탐지는 사용하지 않았다.
- 판권상 초판 발행일은 2026-10-21이다. 이는 제공 PDF의 표기이며 제작일 이후의 실제 발행 여부를 외부 확인하지 않았다.
- PDF쪽은 물리 페이지를 1부터 센다. 인쇄쪽과의 차이가 장별로 바뀌므로 단일 변환식을 쓰지 않는다.
- 파일명·현재 SHA-256·쪽 대응·33개 주요 소절은 [source.json](../source.json)에 있다. 2026-10-14의 현재 파일은 109,617,691바이트이며, 이전 초안에 기록된 원본과 지문이 달라 새로 추출했다. 이전 추출 기록은 이력으로만 보존했다.

## 추출 복구와 확인 한계

현재 PDF 66–68쪽은 텍스트 레이어가 추출된다. 원본 이미지와 대조해 종목 선정의 다섯 조건, 호가 두께의 자금 규모별 의미, 재료 절 전환 및 인쇄 68–70쪽을 확인했다. 이전 초안의 ‘추출 공백·Vision OCR 복구’ 기록은 이전 원본의 기록이며 이번 파일의 상태로 설명하지 않는다.

현재 원본을 `pdftotext`와 쪽별 `-layout`로 새로 추출했다. 추출기가 감지한 42장은 화면 순위·표 숫자의 오탐이며, 차례 PDF 9–12쪽에서 실제 7장·주요 소절 33개를 확인했다. 장별 본문 대조와 선별 시각 검증의 범위는 [검토 기록](validation.md)에 있다.

다른 쪽의 OCR 차트 잡음은 검증 없는 가격·단위로 옮기지 않았다. 정확한 숫자나 화면 연결이 필요한 요청에는 다시 확인할 원본 쪽을 안내한다. [검토 기록](validation.md)은 검증한 범위와 한계를 구별한다.
