# 종가 베팅: 하루의 강함을 다음 날까지 가져갈 근거 만들기

## 참고 범위와 사용 한계

- **참고 범위:** 『실전 시황 트레이딩』 4장 「종가 베팅: 진입장벽이 가장 낮은 매매법」, 인쇄 103–143쪽. 원문 대조 범위는 PDF 100–140쪽이다.
- **정의:** 다음 날 시세의 연속성을 기대하며 밤을 넘기는 단기 매매다(인쇄 103쪽 / PDF 100쪽). 마감 부근 확인이 중심이지만 조건이 성립하면 더 이른 진입도 설명한다(인쇄 115쪽 / PDF 112쪽). 당일의 한 순간을 맞히는 방식이 아니라, 하루 동안 확인한 관심·거래대금·수급·가격 흐름이 마감까지 유지되는지 판단한다(인쇄 103–104쪽 / PDF 100–101쪽).
- 이 글은 원문의 판단 절차를 재구성한 참고 도구이며 현재 매수 추천이나 수익 보장을 뜻하지 않는다. 밤사이 뉴스·해외 시장 때문에 갭 하락이 날 수 있고, 장중 관찰이 불가능하면 다음 날 대응 자체가 제한된다.

## 핵심 관점: “내일 아침 가장 강할 종목은 무엇인가?”

종가 베팅은 직장인과 초보자에게 진입장벽이 낮다(인쇄 103쪽 / PDF 100쪽). 하루 종일 반복 매매하지 않고, 낮에 돈의 흐름을 정리한 뒤 마지막에 한 번 판단할 수 있기 때문이다(인쇄 103–104쪽 / PDF 100–101쪽). 초보에게는 여러 기법을 즉흥적으로 섞는 일을 줄이고, 당일 수급과 주도주를 끝까지 관찰하는 습관을 만든다는 장점도 있다(인쇄 104쪽 / PDF 101쪽). 반면 보유가 밤을 넘으므로 해외 증시 급락·돌발 악재에 따른 갭 하락, 자금이 하루 묶여 회전율이 떨어지는 위험을 감수해야 한다(인쇄 104쪽 / PDF 101쪽).

따라서 **강한 종목**이라는 말만으로는 부족하다. 전일 종가 위인지, 당일 고가를 만든 뒤 눌림에서 다시 살아나는지, 신고가·라운드 피겨처럼 다수가 보는 가격인지, 애프터에서 실제 거래대금이 있어 빠져나올 수 있는지를 한 묶음으로 본다(인쇄 114–115쪽 / PDF 111–112쪽). 애프터가 오래 열린다는 사실은 유동성을 보장하지 않는다(인쇄 114쪽 / PDF 111쪽). 호가가 비어 있으면 원하는 가격의 청산은 어렵다(인쇄 114쪽 / PDF 111쪽).

## 사전 확인: 오후 관찰에서 종목 분류까지

원문 개인 루틴은 오후 1–2시에 당일 누적 실시간 종목 조회 순위를 보고, 미국 증시(특히 나스닥 선물·지수)와 당일 지수를 움직일 변수(예: WTI유)를 함께 점검하는 것이다(인쇄 104–105쪽 / PDF 101–102쪽). 조회 상위권은 변동성과 거래대금이 이미 발생했을 가능성이 높은 후보군일 뿐, 자동 매수 목록이 아니다(인쇄 105쪽 / PDF 102쪽). 초보자는 [0198] 조회 순위로 돈의 흐름부터 익히고, 대안으로 [0186] 거래대금 상위를 볼 수 있다(인쇄 105쪽 / PDF 102쪽).

**조건 → 판단 → 실행 → 철회**는 다음과 같다.

1. 외국인·기관의 매수와 지수 상승이 함께 나타나고, 대형주와 같은 섹터의 소부장까지 조회 상위권에 보이면 지수 관련 주도주 후보로 분류한다(인쇄 105–106쪽 / PDF 102–103쪽). 기관 수급은 하루 종일 매수하는 성향이 있어 저자의 개인적 관찰에서 더 중시된다(인쇄 105쪽 / PDF 102쪽). 이는 확률 판단이지 보편적 예측 법칙이 아니다(인쇄 105쪽 / PDF 102쪽).
2. 지수가 약하고 상위권도 전반적으로 약하면 오후에 억지로 진입하지 않는다(인쇄 108쪽 / PDF 105쪽). 애프터의 새 뉴스와 실제 반응을 끝까지 보거나, 개별주라면 비중을 낮춘다(인쇄 108쪽 / PDF 105쪽). 주도주가 없고 새 시세도 없을 때만 개별 이슈·개별 수급 종목을 대안으로 검토한다(인쇄 120쪽 / PDF 117쪽).
3. 전일 종가 위의 양봉, 한 차례 눌림, 다시 당일 고가로 향하는 흐름과 의미 있는 가격대를 함께 확인해 진입한다(인쇄 114–115쪽 / PDF 111–112쪽). 양봉만 보고 즉시 사지 않는다(인쇄 115쪽 / PDF 112쪽). 지수 관련주는 미국 흐름을 더 본 뒤 저녁에 판단한다(인쇄 118쪽 / PDF 115쪽).
4. 당일 고가를 향하는 흐름에 올라탄 뒤 평균단가를 깨는 등 즉시 나와야 할 흐름이 무너지면 주저 없이 손절한 뒤 다시 자리 잡을 생각을 한다(인쇄 117쪽 / PDF 114쪽). 재진입은 새 근거가 생길 때만 검토한다. 반면 **투매 구간의 100분할 매수는 사전에 정한 라운드 피겨 가격대를 손절 기준으로 삼는 별도 접근**이다(인쇄 117쪽 / PDF 114쪽). 금액·가격 간격을 새로 정하거나 모든 종가 진입을 평균단가 손절로 합치지 않는다.
5. 저자는 결과가 이분법적인 실적·계약 발표에 직접 엮인 종가 베팅을 배제한다고 설명한다(인쇄 117쪽 / PDF 114쪽). 그러나 SK하이닉스·삼성전자-1 사례에서는 **나흘 조정 뒤 반등·대체시장 자금 유입·야간 선물 상승·WTI 하락·기관 매수**를 근거로 엔비디아 실적 발표 전 진입했다(인쇄 126–127쪽 / PDF 123–124쪽). 신고가 과열 상태에서 발표를 기다렸다면 진입하지 않거나 비중을 줄였을 것이라는 단서도 있다(인쇄 126쪽 / PDF 123쪽). 일반 설명과 개인 예외를 함께 보존하며 조정 일수만으로 자동 진입을 허용하지 않는다. 전쟁·지정학 위험처럼 밤사이 변수가 큰 때에는 비중을 낮추는 설명도 구분한다(인쇄 117쪽 / PDF 114쪽).

### 유형별 진입 시간과 비중의 원문 문맥

저자는 시황 조건이 모두 성립한 주도주·시세 초입에서 오후 2시부터 일찍 진입하기도 하고, 개별주는 오후 7시 이후 매매한다고 적는다(인쇄 142쪽 / PDF 139쪽). 전일 종가 위 흐름을 보고 오전 10시부터 매수한 설명도 있다(인쇄 115쪽 / PDF 112쪽). 반면 지수 영향을 강하게 받는 주도주는 미국 흐름을 더 확인하기 위해 저녁 7–8시까지 기다리는 설명이 있다(인쇄 118쪽 / PDF 115쪽). 유형·시황·확인된 조건이 다른 개인 운용이며 어느 시간을 공통 진입 시각으로 고정하지 않는다. 직장인의 가용 시간과도 구분한다.

미수를 쓰지 않는다는 전제에서 저자는 주도주·시세 초입에는 자신의 비중 **70% 이상**, 개별주에는 **20–50%**를 사용하는 대비를 설명한다(인쇄 120쪽 / PDF 117쪽). 이는 종가 유형 간 개인 운용이며 돌파의 첫 진입 50–70%(인쇄 152쪽 / PDF 149쪽), 6장의 첫 진입 절반 미만(인쇄 238–239쪽 / PDF 233–234쪽)과 다른 문맥이다. 사용자의 권장 비중으로 변환하거나 하나의 공통 수치로 합치지 않는다.

**별도 반등 접근:** 저자는 주도 대형주의 반등을 볼 때 전일 저가를 참고해 작게 매수하기도 한다(인쇄 115쪽 / PDF 112쪽). 전일 종가 위 양봉·눌림·고가 재접근과 같은 진입 모양으로 합치지 않으며, 임의 금액·손절선을 추가하지 않는다.

## 거래 세션과 실행 제약

원문은 하루 거래 시간을 NXT 프리마켓 **08:00–08:50**, 정규장 **09:00–15:30**, KRX 애프터 **16:00–20:00**, NXT 애프터 **15:40–20:00**으로 제시한다(인쇄 113쪽 / PDF 110쪽). 이어 대부분의 종목이 저녁 8시까지 열려 있다고 설명하되, 실제 돈이 도는 종목은 따로 있다고 덧붙인다(인쇄 114쪽 / PDF 111쪽). 이는 **책이 제시한 당시 거래 세션 표기**이며 현재 운영 시간·대상 종목의 유효성을 이 자료에서 검증하지 않는다. 실제 실행 전에는 거래소·증권사 화면에서 종목별 NXT 거래 가능 여부와 애프터 유동성을 다시 확인해야 한다.

정규장 마감에 서두르기보다 애프터에 미국 선물·뉴스·체결을 확인할 수 있다는 것이 장점이다(인쇄 113쪽 / PDF 110쪽). 다만 다음 날 프리 대응이 가능한지는 NXT 대상 여부에 달려 있다(인쇄 112–113쪽 / PDF 109–110쪽). 그래서 원문 체크리스트는 프리·애프터에서 거래되는 종목인지와 밤사이 악재에 대응할 수단이 있는지를 묻는다(인쇄 143쪽 / PDF 140쪽). 장중 또는 프리 관찰을 할 수 없는 사람은 ‘밤을 넘긴다’는 위험을 줄일 수 없으므로, 진입 기준보다 **다음 날 청산 가능 시간과 주문 가능 여부**를 먼저 확인해야 한다.

저자는 이 체크리스트에서 **정규장에만 거래되는 종목은 종가 베팅할 이유가 없다**고 설명하며 프리·애프터 거래 가능 여부를 후보 선정 조건으로 둔다(인쇄 143쪽 / PDF 140쪽). 이는 저자의 종가 베팅 규칙이다. 현재 종목별 거래 지원 여부를 확인하는 절차와 구별하며, 정규장 상따의 예외 사례에 그대로 적용하지 않는다.

## 원문 매매일지의 판단 흐름 재구성

**LIG넥스원(현 LIG디펜스앤에어로스페이스) 사례.** 중동 전쟁·호르무즈 해협 이슈로 유가·방산 테마가 움직이고 지수는 약한 날이었다(인쇄 122쪽 / PDF 119쪽). 저자는 지수 추종주보다 헤지 성격의 방산을 봤다(인쇄 122쪽 / PDF 119쪽). 전일 상한가 가격 위 마감은 아니었지만 정규장 마감가와 대체거래소 마감 흐름, 방산 동반 관심, 신고가 위치를 결합해 저녁 7시 이후 두 번 나누어 진입했다(인쇄 122–123쪽 / PDF 119–120쪽). 재구성의 핵심은 특정 종목이나 가격을 외우는 것이 아니라, **약한 지수 → 관련 테마 동반 강세 → 정규장·애프터 마감 방어 → 다음 날 기대**라는 연결이다.

**한화시스템 사례.** 저자는 약한 지수와 반도체에서 방산·유가로 옮겨가는 돈, 조회 상위권 방산주의 동반 관심을 먼저 확인했다(인쇄 124쪽 / PDF 121쪽). 상한가 여부와 별개로 당일 고가 마감과 애프터 마감까지의 분할 매수를 계획했고, 실제로 상한가에 들어간 뒤 다음 날 대체거래소 갭에서 매도했다(인쇄 124–125쪽 / PDF 121–122쪽). 상한가 진입 자체를 근거로 산 상따와 종가 관점의 매매를 구별한다(인쇄 124쪽 / PDF 121쪽).

**SK하이닉스·삼성전자-2 사례(2026-05-25).** 저자는 두 종목의 2배 ETF 출시 기대, 코스피 신고가, WTI 하락, 미국 선물 상승과 종전 협상 분위기를 묶어 보았다(인쇄 128쪽 / PDF 125쪽). SK하이닉스가 전일 종가·고가 위를 유지하고 애프터 마감까지 당일 고가로 향하자 분할 매수했다(인쇄 128쪽 / PDF 125쪽). 기관이 지수를 이끌던 수급도 보유 근거였다(인쇄 128–129쪽 / PDF 125–126쪽). 미국 시장이 사흘 휴장 뒤 다시 열리는 일정과, 이후 마이크론이 약 20% 급등해 다음 날 상승에 영향을 주었다는 사후 설명은 구별한다(인쇄 128쪽 / PDF 125쪽). 사후 급등 결과를 진입 전에 이미 알았던 정보로 바꾸지 않는다.

**TCC스틸 사례.** 먼저 철강 테마주 다수는 호가가 얇고 거래대금도 충분히 터지지 않아 후보에서 제외했다(인쇄 132–133쪽 / PDF 129–130쪽). 그중 상대적으로 무거운 넥스틸에는 뉴스가 나왔지만, 저자는 미리 정한 매수 가격을 빠른 상승으로 놓쳐 추격하지 않았다(인쇄 133쪽 / PDF 130쪽). 이후 **넥스틸이 상한가에 들어가려는 움직임**을 보일 때, 당시 프리마켓 거래가 가능했던 TCC스틸을 별도 후보로 전환했다(인쇄 133–134쪽 / PDF 130–131쪽). TCC스틸이 2만 원을 돌파하며 진입했고, 신고가 돌파에서는 약 50%를 익절한 뒤 대체거래소 2만 2,000원까지 다시 분할 매수할 계획을 세웠다(인쇄 134쪽 / PDF 131쪽). 너무 빠른 상승에서는 물량을 조금 더 정리했고, 장 막판 매수세가 살아나자 불타기로 보유를 늘려 다음 날 갭에서 전량 매도했다(인쇄 134쪽 / PDF 131쪽). 즉 첫 단계의 유동성 부족 후보 제외, 넥스틸의 놓친 자리와 추격 회피, TCC스틸의 새 조건 충족·재진입은 구분해야 한다. 모든 가격·분할은 저자의 개인 사례다.

**광주신세계 사례.** 지역 산업단지 기대 테마에서 작은 후보의 체결 한계를 보고 당시 프리·애프터 거래가 가능했던 후보로 관찰을 옮겼다(인쇄 135쪽 / PDF 132쪽). 뉴스 직후가 아니라 금호타이어와 관련 종목의 거래대금·동반 움직임을 확인했다(인쇄 136쪽 / PDF 133쪽). 저자는 4만 6,000원 부근의 회복·방어를 보고 4만 5,500–4만 6,300원에서 분할로 모았고, 강한 상승 때 일부 익절했으나 대부분은 보유했다(인쇄 136쪽 / PDF 133쪽). 대장 금호타이어의 상한가와 다음 날 동적 VI 때 후속주로 돈이 이동할 수 있다는 가설로 보유를 이어갔고, 광주신세계도 상한가까지 보유했다고 서술한다(인쇄 135–137쪽 / PDF 132–134쪽). 5만 원은 당시 계획의 가격대이며(인쇄 136쪽 / PDF 133쪽) 현재 목표가나 자동 보유 조건이 아니다. 원문은 이 보유 결론과 수익을 설명하지만 전량 매도의 정확한 시각·가격·수량을 본문에 명시하지 않는다.

**펄어비스 사례.** 저자는 게임 ‘붉은사막’의 단기간 300만 장 판매와 손익분기점 돌파를 당시 회사 고유 재료로 설명했다(인쇄 138쪽 / PDF 135쪽). 게임 섹터 전체의 자금 유입과 구별하고, 이미 하락한 가격 위치에서 전일 외국인·기관 양매수와 애프터 프로그램 유입을 추가 근거로 보았다(인쇄 138–139쪽 / PDF 135–136쪽). 이 판매량은 책의 당시 서술이며 현재 판매 실적이 아니다. 본문이 정하지 않은 진입·손절 가격이나 다음 날 매도 시각을 보충하지 않는다.

**한온시스템 사례.** 특별한 단일 이슈보다 외국인 수급·정규장 종가 방어·프로그램 유입·250일 신고가를 함께 보았다(인쇄 140쪽 / PDF 137쪽). 저자는 다음 날 큰 갭이 나오면 바로 익절하고, 그렇지 않으면 5,000원까지 트레이딩한다는 분기를 세웠다(인쇄 140쪽 / PDF 137쪽). 실제 흐름은 그 가격에 정확히 도달하지 않았어도 부근에서 대응한 사례다(인쇄 140–141쪽 / PDF 137–138쪽). 원문 사례의 가격·분기를 사용자 주문값으로 바꾸지 않는다.

실패 대응의 선명한 예는 **SK하이닉스·삼성전자-3(2026-07-14~15)의 삼성전자 재진입**이다(인쇄 130–131쪽 / PDF 127–128쪽). 저자는 전저점 이탈에서 기존 비중의 **70%만 부분 손절**해 약 300만 원의 추가 손실을 감수했고, 남은 물량을 즉시 전량 정리하지 않은 채 흐름을 관찰했다(인쇄 130쪽 / PDF 127쪽). 이후 시가·저가를 깨려는 구간에서 프로그램 수급이 가격대를 지키는 것을 다시 확인하고 전일 종가 부근에서 재진입했다(인쇄 130–131쪽 / PDF 127–128쪽). 70%와 손실 금액은 저자의 개인 사례이며, 원문 본문은 남은 물량의 별도 청산 비율을 명시하지 않는다. 손절은 최초 가설을 무효화하는 실행이고, 재진입은 손실을 만회하려는 행위가 아니라 **새 근거가 생겼을 때의 새 판단**이어야 한다.

### 동일 사례의 CPI/PPI 표기 차이

**SK하이닉스·삼성전자-3(2026-07-14~15)**는 종가 절에서 미국 **CPI**로 서술되지만(인쇄 130–131쪽 / PDF 127–128쪽), 같은 거래를 다시 다룬 수급 절에서는 **PPI**라고 적는다(인쇄 193–195쪽 / PDF 190–192쪽). 제공 원문 내부 불일치다. 같은 거래의 삼성전자 손절도 종가 절은 전저점 이탈 뒤 비중의 70% 손절로(인쇄 130쪽 / PDF 127쪽), 수급 절은 전일 종가 가격대 이탈 뒤 2% 이내 손절로(인쇄 195쪽 / PDF 192쪽) 다르게 적는다. 어느 경제지표가 실제 일정이었는지와 어느 손절 서술이 정확한지 이번 책 검수로 확정하지 않으며, 원문 당시 근거와 사후 설명을 구별한다.
