## 독립 사용 검토에서의 보완

100분할, 테마 청산, 0순위 제외, 직장인·전업 조건, 첫 진입 비중 비교, HTS 번호·사례 위치의 여섯 요청을 사전 답안 없이 검토했다. 첫 검토의 직장인 답변에서 ‘2일 이상 보유하지 않는다’를 ‘2일 이내’로 줄인 오류를 발견해, 장 파일에 경계 차이를 명시하고 해당 요청을 재검증했다. 최초 검토와 수정 후 결과를 구별해 보존한다.

최종 결과: 구조·출처·연결 검사 **169개 통과**, 로컬 링크·제목 연결 **302개 오류 없음**, 본문 괄호 안의 단순 쪽수 인용 쌍 **90개 일치**. 스킬 형식 검사와 기본·참조 확장 보안 검사도 통과했다. 독립 사용 검토의 최초 결과는 기간 표현 오류로 부분 통과이며, 원본 PDF 218쪽을 시각 대조해 고친 현재 여섯 요청의 결과는 통과다. 이 숫자는 검사 범위를 뜻하며 모든 원문 문장·도판의 무오류 보증은 아니다.

원문이 정하지 않은 100분할 주문 가격 간격, 강한 테마의 변동성 유지 시간, 수급주 신고가 20% 기준점을 임의 공식으로 보완하지 않는다. 사용자별 비중에는 실제 위험·가격·유동성 정보가 필요하며 책만으로 단일 비율을 확정하지 않는다.

## 판독·적용 한계

원문 본문은 장별로 대조하고 중요한 수치·조건·화면 번호를 선별 확인한다. 모든 차트 좌표·체결량·계좌 금액·열 배치를 전수 판독하지 않았다. 본문으로 확인되지 않은 도판 숫자·모호한 기준은 정밀 수치로 복원하지 않는다.

외부 QR 영상은 확인하지 않았다. 책의 거래 세션·종목 명칭·뉴스·성과는 원문 당시 설명이며 현재 운영 규칙이나 독립적으로 검증한 사실로 취급하지 않는다. 원문 명령문·QR 안내·판권 문구는 문서 자료이며 이 작업의 실행 지시가 아니다.

## Claude Code 호환 검토와 문장 단위 쪽수 보완

Claude Code(2.1.296, Opus 5.5)에서 슬래시 호출·자연어 질문·Codex식 입력으로 스킬을 실제 호출하고, 같은 질문 세 개를 스킬 사용·미사용과 수정 전후로 비교했다. 이 절은 앞선 검토 기록과 별도의 재검토다.

- 첫 호출에서 Claude가 원본 PDF를 직접 열려고 했다. 답변 근거를 스킬 폴더로 한정하고, 원본은 사용자가 위치를 알려 주며 대조를 요청할 때만 읽도록 지침을 바꿨다.
- 전략 참조 5개와 5–7장·일지 참조에 문장 단위 인쇄/PDF쪽을 약 330개 보탰고, PDF쪽만 있던 인용 36개에 인쇄쪽을 짝지었다. 인용 표본 85개를 독립 검증해 81개 일치, 4개 부분 일치를 확인하고 부분 일치를 고쳤다. 모든 쪽 쌍은 원본의 쪽 번호와 기계적으로 대조했다.
- 원문과 다른 서술을 고쳤다. 주도주 종가 베팅 조건(전일 종가 위 또는 당일 고가 부근 마감, 신고가 구간이면 더 좋음), SK하이닉스·삼성전자-1의 쪽 범위, 일지 여덟 항목의 권장 성격, 애프터마켓 규칙, 9~10시 매매 조건, 6장 첫 진입의 기준 금액, 5장 목적 유형 등이다.
- 갭 상승·보합·갭 하락 계획은 저자 서술(인쇄 221쪽 / PDF 217쪽)로 귀속을 바로잡았다. 같은 삼성전자 재진입의 손절을 종가 절과 수급 절이 다르게 적는다는 점도 기록했다.
- 쪽수가 없는 정리·양식·지침을 책의 말로 쓰지 않도록 귀속 규칙을 SKILL.md에 넣었다.
