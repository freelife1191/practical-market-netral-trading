# 참조 자료 색인

이 색인은 스킬의 탐색을 위한 재구성이다. 원문의 새로운 장이나 저자의 별도 프레임워크가 아니다. 필요한 자료만 읽으며 상세 판단은 연결된 원문 범위에서 확인한다.

## 적용 경계

원칙을 해당 조건과 함께 사용한다. 저자의 개인 매매 금액·출금 방식·시간표·화면 설정을 사용자 기본값으로 만들지 않는다. 미확인 시장 자료는 미확인으로 표시한다. 실제 최신 제도·세션·종목·시세 질문은 책만으로 확정하지 않는다.

장·참조 파일은 원문을 합성한 자료이며 모든 그림·뉴스·QR 영상의 복제본이 아니다. 정확한 숫자·화면의 연결은 [출처 메타데이터](../source.json)의 원본 위치로 안내한다.
