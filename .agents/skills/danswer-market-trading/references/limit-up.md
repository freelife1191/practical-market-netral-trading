# 상따 매매: 하이리스크·하이리턴

## 원문 범위와 용도

이 자료는 『실전 시황 트레이딩』 PDF 195~204쪽(인쇄 198~207쪽)의 상따(상한가 따라잡기) 내용을 정리한다. 상따는 강하게 오른 종목을 매수해 다음 날 갭을 노리는 방식이라 종가 베팅과 목적이 닿아 있지만, 저자는 더 큰 갭 하락도 가능한 고위험·고수익 매매로 규정한다(인쇄 198쪽 / PDF 195쪽). 아래 수치와 조건은 저자의 당시 방식이며, 과거 사례·성과·종목을 현재의 추천 또는 보장으로 바꾸지 않는다.

## 저자 규칙: 무엇을 고를 것인가

상한가라는 결과만 보고 진입하지 않는다(인쇄 199쪽 / PDF 196쪽). 먼저 시장 상황, 상한가 이유, 다음 날까지 기대감이 남을 이유를 확인한다(인쇄 198쪽 / PDF 195쪽). 저자는 이미 여러 날 오른 상한가보다 **변동성이 막 생긴 시세 초입**을 선호한다(인쇄 199쪽 / PDF 196쪽). 초입 종목은 호가가 얇아 거래대금이 아주 크지 않을 수 있지만, 가볍게 오르며 큰 갭을 만들 수 있다는 관찰이다(인쇄 199쪽 / PDF 196쪽).

개인은 뉴스의 파급을 전문가처럼 단정하기 어렵기에 거래대금·변동성·동류 종목의 동반 움직임으로 파급을 가늠한다(인쇄 199–200쪽 / PDF 196–197쪽). 30초 기준 실시간 종목 조회에서 한 종목이 약 20% 이상 오르면 관찰하고, 그 종목에서 테마와 관련 뉴스를 역으로 찾는다(인쇄 199–200쪽 / PDF 196–197쪽). 예컨대 로봇 관련 종목이 튀면 로봇 테마와 관련 대기업 뉴스, 비슷한 사업 종목들의 동반 강세를 확인하는 순서다(인쇄 200쪽 / PDF 197쪽). ‘뉴스를 보고 종목을 찾는 것’과 ‘급등 종목에서 원인을 찾아 테마군을 확인하는 것’의 차이를 저자는 강조한다(인쇄 200쪽 / PDF 197쪽).

정규장 상따는 개별주 장세가 강하거나 지수가 박스권·하방이라 애매할 때, 대체 수단으로 낮은 비중만 쓴다(인쇄 201쪽 / PDF 198쪽). 정규장 이후에는 여러 종목이 상한가가 된 테마에서 매수 대기 자금이 후속주로 갈 수 있으므로, 다음 날 프리마켓 거래 지원 여부를 확인한 뒤 애프터마켓 상따를 선호한다고 적는다(인쇄 201쪽 / PDF 198쪽). 저자는 3연상 이후에는 하한가 위험을 이유로 극도로 조심하고, 이슈가 매우 크지 않으면 무리하지 않으며 시가총액 500억 원 이하 종목은 거래하지 않는다고 밝힌다(인쇄 201쪽 / PDF 198쪽).

## 저자 규칙: 진입·비중·손절·다음 날

1. 시황과 돈의 흐름을 읽어 상한가 가능성이 높은 종목을 찾고, 저자는 보통 25% 구간부터 모아간다(인쇄 201쪽 / PDF 198쪽). 단, 한 번에 전부 사지 않는다(인쇄 202쪽 / PDF 199쪽).
2. 단일 종목이 아니라 섹터·테마의 유사 종목 변동성이 유지되는지를 보며 분할 진입한다(인쇄 202쪽 / PDF 199쪽). 동류 종목이 식으면 상한가 종목 하나만의 힘이라고 단정하지 않는다.
3. 비중은 호가 두께에 맞춘다(인쇄 202쪽 / PDF 199쪽). 저자의 예시는 한 호가가 약 500만~1,000만 원이면 최대 1억 원, 약 1,000만~2,000만 원이면 최대 2억 원까지라는 당시 운용 사례다(인쇄 202쪽 / PDF 199쪽). 고정 한도가 아니며, 3연상 이후 종목을 매매하더라도 최대 비중의 10분의 1 정도만 쓴다고 한다(인쇄 202쪽 / PDF 199쪽).
4. 상한가가 풀리면 반드시 상황을 다시 판정한다(인쇄 202쪽 / PDF 199쪽). 전체 변동성·거래대금·분위기상 돈의 흐름이 유지되면 재상한가 가능성을 보거나 더 매수할 수도 있으나, **테마 대장주의 상한가가 풀리고 급락**하면 즉시 손절한다(인쇄 202–203쪽 / PDF 199–200쪽). 퍼센트 고정 손절 대신 테마 생존 여부를 기준으로 한다는 저자의 규칙이다(인쇄 202–203쪽 / PDF 199–200쪽).
5. 다음 날의 목적은 갭 자체다(인쇄 203쪽 / PDF 200쪽). 갭 상승이면 프리마켓에서 빠르게, 또는 정규장 시초가에 매도한다(인쇄 203쪽 / PDF 200쪽). 갭이 없거나 갭 하락이어도 무조건 매도한다(인쇄 203쪽 / PDF 200쪽). 목적이 어긋난 뒤 보유 이유를 새로 만들지 않는 것이 원칙이다(인쇄 203쪽 / PDF 200쪽).

## 원문 사례 재구성

- **선도전기(2026-04-29 이후)**: 전력·에너지에 대한 시장 관심을 지켜보던 중, 거래정지 해제 뒤 30초 순위에서 처음 보는 종목이 15%, 20%로 빠르게 오르는 것을 포착했다(인쇄 203–204쪽 / PDF 200–201쪽). 저자는 4년간 거래가 정지된 사이의 코스피 상승분과 유사 실적 종목 비교로 저평가라고 보아, 당시 2~3연상 이상도 가능하다고 판단했다(인쇄 204쪽 / PDF 201쪽). 상한가 가격에서 매물로 밀리려 하자 물량을 한 번 조절했으나, 원문은 이 조절의 비율과 손절 여부를 밝히지 않는다(인쇄 204쪽 / PDF 201쪽). 다음 날 점상한가 이후에도 추가 매수·보유했으며, 5월 6일 상한가가 풀릴 때 전량 익절했다고 서술한다(인쇄 204–205쪽 / PDF 201–202쪽). 이 가치 판단과 여러 날 보유는 저자의 개별 사례이며 연상 예측 공식이나 일반적인 다음 날 갭 매도 원칙을 대체하지 않는다.
- **넥스틸(2026-04-28~29)**: 철강 테마의 얇은 호가·낮은 시가총액 종목은 피하고, 특징주 뉴스 후 넥스틸이 빠르게 상한가로 가는 것을 관찰했다(인쇄 205쪽 / PDF 202쪽). 상승 중의 큰 양방향 변동성에서는 매매하지 않고 상한가 안착을 기다린 뒤 상따로 접근해, 다음 날 대체거래소 상승에서 매도한 사례다(인쇄 205쪽 / PDF 202쪽).
- **에브리봇(2026-07-21~22)**: 삼성전자의 로봇 사업 뉴스 뒤 프리마켓 거래가 안 되는 관련주가 먼저 상한가에 들어가는 것을 보고, 프리·애프터 거래 가능한 대장을 기다렸다(인쇄 206쪽 / PDF 203쪽). 에브리봇이 강해지자 25%부터 모으고 상한가 진입 흐름에서 추가 매수해 다음 날 갭에 매도했다(인쇄 206–207쪽 / PDF 203–204쪽). 저자는 이를 ‘상한가를 한 점에 사는 공식’이 아니라 대장이 확실해지는 과정에 유연하게 대응한 사례로 설명한다(인쇄 207쪽 / PDF 204쪽).

## 체크리스트와 오판

- [ ] 시세 초입인가, 상한가 이유와 다음 날까지 이어질 기대를 설명할 수 있는가? (인쇄 198–199쪽 / PDF 195–196쪽)
- [ ] 30초 순위의 급등 뒤 관련 뉴스와 동류 종목의 동반 변동성을 확인했는가? (인쇄 199–200쪽 / PDF 196–197쪽)
- [ ] 정규장·애프터마켓·다음 날 프리마켓의 거래 가능 여부와 시간 차이를 확인했는가? (인쇄 200–201쪽 / PDF 197–198쪽)
- [ ] 호가 두께에 맞춘 분할 비중이며, 3연상·저시총 위험을 별도로 낮췄는가? (인쇄 201–202쪽 / PDF 198–199쪽)
- [ ] 상한가 이탈 때 대장·테마의 급락과 전체 분위기를 확인할 준비가 있는가? (인쇄 202–203쪽 / PDF 199–200쪽)
- [ ] 다음 날 갭이 없거나 하락해도 목표가 끝났다는 규칙으로 매도할 준비가 있는가? (인쇄 203쪽 / PDF 200쪽)

흔한 오판은 상한가 자체를 재료의 지속성으로, 한 종목의 급등을 테마 동반 강세로, 얇은 호가를 큰 비중을 넣어도 되는 유동성으로 바꾸는 것이다. 원문은 상따에 별도 체크리스트를 두지 않았다고 명시했으므로(인쇄 207쪽 / PDF 204쪽) 위 목록은 저자의 본문 조건을 재배열한 적용 양식이며 새 매매 규칙이 아니다.
