# 루틴과 매매일지: 관찰을 다음 행동으로 바꾸는 기록

> 원문 범위: PDF 251~276쪽 / 인쇄 257~282쪽, 직장인 시간 활용은 PDF 215~218쪽 / 인쇄 219~222쪽. 이 문서는 원문이 권하는 기록 항목과, 스킬 사용을 위해 새로 만든 적용 양식을 분리한다.

## 원문이 권하는 일지 내용

원문은 종목·수익·손실만 적는 일지를 영수증에 비유한다(인쇄 269쪽 / PDF 263쪽). 좋은 일지는 ‘나의 매매를 타인에게 명확히 설명하고 설득할 수 있는가’를 기준으로 한다(PDF 263~264, 인쇄 269~270). 원문은 일지를 아래 여덟 항목으로 작성하면 좋다고 권한다(인쇄 270쪽 / PDF 264쪽).

1. **그날의 시장**: 지수 관련주·테마주 중 무엇이 움직였는지, 어느 섹터에 거래대금이 집중됐는지, 종가 베팅·돌파 등 내 방식이 맞는 시장이었는지(인쇄 270~271쪽 / PDF 264~265쪽).
2. **종목 선택 이유**: 대장성, 거래대금, 동테마 내 선행성, 신고가·전고점 등 모두가 주목한 자리였는지(인쇄 271쪽 / PDF 265쪽).
3. **진입 시점의 근거**: 장 초반부터 준비한 매매, 장중 수급 확인, 오후 연속성 확인 중 무엇이었는지와 가격대(인쇄 271쪽 / PDF 265쪽).
4. **객관 지표**: 지수 위치, 거래대금, 외국인·기관 수급, 프로그램 매매, 대장·후속주 움직임 중 실제 매수 전에 본 것(인쇄 271쪽 / PDF 265쪽).
5. **비중 이유**: 첫 진입의 이유, 남겨 둔 추가 여력, 추가 매수 때 새로 확인한 사실(인쇄 272쪽 / PDF 266쪽).
6. **손절과 매도 기준**: 가격뿐 아니라 대장주·프로그램·테마 연속성이 어떻게 변할 때 행동할지(인쇄 272쪽 / PDF 266쪽).
7. **매매 당시 감정**: FOMO, 복구 욕구, 과신, 수면 부족·숙취 같은 상태가 판단에 미친 영향(인쇄 272쪽 / PDF 266쪽).
8. **다음 매매에서 바꿀 한 가지**: 추상이 아닌 다음 거래에서 관찰·실행할 구체적 행동(인쇄 272쪽 / PDF 266쪽).

사후에 처음 보는 지표를 찾아 근거처럼 쓰지 않는다. 원문은 이것을 복기가 아니라 결과에 이유를 끼워 맞추는 일로 본다(PDF 265~267, 인쇄 271~273). 저자가 예시로 든 ‘첫 진입은 계획한 총매수 금액의 60%를 넘기지 않는다’는 문장(인쇄 273쪽 / PDF 267쪽)은 좋은 개선 문장의 **형식**을 보인 것이지, 이 스킬이 모든 사용자에게 적용하는 고정 비중 규칙이 아니다.

## 새 적용 양식: 네 구간 루틴

아래는 원문의 시간대·기록 원칙을 현재의 개인 세션과 생활에 맞게 실행하기 위해 만든 **새 양식**이다. 시간을 고정하지 말고, 실제로 대응 가능한 시간과 HTS의 현재 세션을 적는다.

### 장전: 가설과 금지 조건

| 기록 칸 | 작성 내용 |
| --- | --- |
| 확인 시각·세션 | 현재 시각, 실제 HTS 시장 구분, 데이터 갱신 시각 |
| 외부 환경 | 해외지수·선물·환율·주요 일정 중 오늘 내 시장에 관련 있는 사실 |
| 전일 검증 | 전일 주도 섹터·종목의 연속성, 보유 종목 공시·뉴스 |
| 관심 종목 | 종목이 아니라 ‘왜 관찰하는지’와 확인할 조건 |
| 가설의 무효 조건 | 어떤 지수·수급·뉴스·가격 변화면 가설을 버릴지 |
| 거래 금지 조건 | 대응 시간 부족, 수면·건강 저하, 세션·주문 상태 불명, 시장 부적합 등 |

원문의 전업 루틴은 장 전 해외 증시·뉴스·관심 종목을 정리하고 중요 가격대를 다시 보는 데서 시작한다(PDF 257~258, 인쇄 263~264). 직장인 양식은 같은 일을 출근 전으로 옮기되, 장중 대응이 불가능하면 그 사실도 가설의 제약으로 적는다.

### 장중: 관찰과 결정 분리

| 기록 칸 | 작성 내용 |
| --- | --- |
| 관찰 단위 | 지수 위치, 거래대금 이동, 주도 섹터, 대장·후속주의 관계 |
| 가설 대조 | 장전 가설과 실제 흐름이 일치·불일치하는 사실 |
| 새 정보 | 뉴스·공시·수급 변화와 확인 시각 |
| 행동 | 관찰 유지 / 후보 압축 / 계획 거래 / 무포지션 중 하나 |
| 행동 근거 | 최초 근거가 강화·약화·무효 중 무엇인지 |
| 상태 점검 | 피로·조급함·복구 욕구·업무 제약이 판단을 흔드는지 |

원문은 9~10시를 가장 집중하는 시간으로 두되, 시장이 열렸다는 이유만으로 시가 매매를 하지 말고 시나리오와 실제 수급이 맞을 때만 매매하라고 한다(PDF 259, 인쇄 265). 반대로 점심의 식사·휴식은 이후 집중력을 위한 준비다(인쇄 265~266쪽 / PDF 259~260쪽). 직장인은 점심을 주문 시간이 아니라 조회 순위·거래대금·주도 섹터를 확인해 후보를 압축하는 시간으로 쓸 수 있다(PDF 215~216, 인쇄 219~220)(인쇄 222쪽 / PDF 218쪽).

### 장후: 사실 기반 복기

| 기록 칸 | 작성 내용 |
| --- | --- |
| 시장 요약 | 오늘 돈이 모인 곳과 내 방식의 적합성 |
| 거래별 여덟 항목 | 위 ‘원문이 권하는 일지 내용’을 거래마다 작성 |
| 미거래 후보 | 매매하지 않은 강한 종목과, 하지 않은 이유·놓친 조건 |
| 가설 판정 | 맞음/틀림이 아니라 근거 유지·무효·불충분으로 기록 |
| 한 가지 수정 | 다음 거래에서 관찰하거나 멈출 행동 하나 |
| 내일 준비 | 관심 종목, 확인할 뉴스·일정, 주문 전 재확인 항목 |

정규장 종료 뒤 저자는 매수·매도 가격과 손익에 더해 진입·청산 이유와 당시 감정을 기록한다(PDF 261, 인쇄 267). 애프터마켓에서는 정규장부터 종가 베팅한 종목에 대응하고, 보유 종목이 없으면 후보가 나올 때 종가 베팅을 진행한다. 시간이 길어 판단력이 흐트러지기 쉬우므로 호가창만 계속 보지는 않는다(인쇄 267쪽 / PDF 261쪽). 실제 세션 시간·종목 범위·주문 가능 여부는 [HTS 세팅](hts-setup.md)의 세션 점검을 먼저 따른다.

### 주기 점검: 하루 결과를 넘어서기

| 주기 | 질문 | 기록 산출물 |
| --- | --- | --- |
| 주 1회 | 어떤 시황에서 내 가설이 반복적으로 맞거나 무효가 됐는가? | 반복 조건 1개, 중단할 행동 1개 |
| 월 1회 | 손실 거래의 공통 감정·수면·과잉 거래·근거 변경은 무엇인가? | 위험 신호 목록과 환경 수정안 |
| 시드 변경 전 | 금액이 바뀌어도 손절·휴식·종목 압축이 유지됐는가? 유동성·호가를 감당하는가? | 확대·유지·축소 결정 근거 |
| 슬럼프 때 | 시장이 내 방식에 맞지 않는가, 원칙을 어겼는가? | 휴식 또는 단일 행동 수정 계획 |

원문의 슬럼프 회복은 과거의 큰 수익을 재현하는 목표가 아니라 비중을 줄이고, 잘하는 하나에 집중하고, 무포지션을 허용하며, 수면·식사·운동을 회복하는 데 있었다(PDF 270~272, 인쇄 276~278). 슬럼프 당시 선배가 아침 수익 뒤 바로 종료해 작은 성과로 자신감을 회복하라고 한 조언도 있다(인쇄 277쪽 / PDF 271쪽). 이를 모든 날의 수익 후 종료 규칙으로 확대하지 않는다. 따라서 주기 점검은 월 수익 순위표가 아니라 과정의 왜곡을 찾는 자리다.

## 즉시 쓸 수 있는 거래 기록 카드

```text
날짜 / 현재 세션 / 기록 시각:
오늘 시장(지수·주도 섹터·거래대금):
관찰 종목과 선택 이유:
실제로 본 지표·뉴스(확인 시각 포함):
진입 또는 미진입의 근거:
진입 시각·가격 / 청산 시각·가격:
실현손익·수익률(수수료·세금 포함 여부):
비중·추가 여력의 이유:
무효 조건과 손절·매도 계획:
실제 행동과 근거 변화:
감정·수면·업무 제약 등 상태:
미거래 종목에서 배운 점:
다음 거래에서 바꿀 한 가지:
```

카드는 손익을 숨기라는 뜻이 아니다. 손익은 결과 칸에 남기되, 그 숫자가 위의 판단 과정을 대신하지 못하게 한다. 다른 트레이더의 일지도 수익 규모가 아니라 그 사람이 시장을 본 순서, 기다린 조건, 하지 않은 거래를 중심으로 비교한다(PDF 267, 인쇄 273).
