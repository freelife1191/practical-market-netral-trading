# 빠른 판단표

본문 조건을 확인하는 보조 자료다. 개인 설정과 사례의 수치를 보편 규칙으로 바꾸지 않는다.

| 관찰 | 판단·다음 행동 | 확인 자료 |
|---|---|---|
| 기법은 있는데 오늘 시장 설명이 없다 | 시황·돈 흐름부터 정리 | [02장](chapters/ch02-market-perspective.md) |
| 상승률만 높거나 거래대금만 크다 | 둘의 결합과 주도 섹터·재료를 확인 | [03장](chapters/ch03-stock-selection.md) |
| 거래대금 1위라 테마 대장이라 부른다 | 테마 내 속도·등락률·후속 확산을 별도 확인 | [테마](references/theme-trading.md) |
| 뉴스가 떴으니 바로 매수하려 한다 | 국내 영향·지속성·실제 반응을 설명 | [선정](references/stock-selection.md) |
| 종가 베팅인데 다음 날 계획이 없다 | 갭 상승·보합·갭 하락 대응부터 작성 | [종가](references/closing-bet.md) |
| 중요한 발표 결과에 매매 성패가 걸린다 | 종가 자료의 일정·홀짝성 배제 조건을 확인 | [종가](references/closing-bet.md) |
| 돌파 후보인데 돈이 다른 종목으로 이동한다 | 주도주·가격대·자금 이동을 재판정 | [돌파](references/breakout.md) |
| 후속주는 오르는데 대장이 멈칫한다 | 대장의 흐름을 기준으로 철회 조건 확인 | [테마](references/theme-trading.md) |
| 프로그램 순매수를 주체 확정으로 본다 | 외국인·기관·시간대·가격 반응을 함께 확인 | [수급](references/flow-trading.md) |
| 상한가에 닿았으니 안심하고 담는다 | 초입·재료·동류·풀림·다음 날 갭을 확인 | [상따](references/limit-up.md) |
| 얇은 호가에 큰 비중을 넣는다 | 청산 때 밀릴 호가와 내 주문 규모를 비교 | [03장](chapters/ch03-stock-selection.md) |
| 매수 근거가 깨져 투자 기간을 늘린다 | 원래 매매의 무효화에 대응 | [06장](chapters/ch06-risk-and-capital.md) |
| 비중부터 정하고 손실을 계산한다 | 감당 손실부터 정해 비중을 다시 검토 | [06장](chapters/ch06-risk-and-capital.md) |
| 추가 매수의 이유가 ‘단가 낮추기’뿐이다 | 근거 강화·수급 확인 없는 물타기인지 점검 | [06장](chapters/ch06-risk-and-capital.md) |
| 장중 대응이 불가능하다 | 본업·다음 날 대응 여건에 맞는 기법 선택 | [05장](chapters/ch05-worker-trading.md) |
| 손익 숫자만 적는다 | 시장·진입·비중·청산의 의사결정을 복기 | [07장](chapters/ch07-routine-and-psychology.md) |
| 수익 압박·포모·슬럼프가 판단을 바꾼다 | 작은 학습 단위와 생활·매매 루틴 재점검 | [07장](chapters/ch07-routine-and-psychology.md) |
| 현재 정보가 없는데 정확한 가격을 요구받는다 | 미확인 항목을 표시하고 실제 자료를 확인 | [실무 양식](patterns.md) |

**구분:** 종가의 다음 날 갭, 돌파의 가격·돈 이동, 테마의 대장 속도, 수급의 주체·지속성, 상따의 상한가·갭 기대는 서로 다른 관찰이다. 공통 고정 손절률 하나로 다섯 무기를 처리하지 않는다.

**저자가 제시한 수치가 필요한 경우:** 각 상세 파일을 읽고 그 수치에 붙은 인쇄/PDF쪽을 함께 옮긴다. 이 판단표에는 개인 운용 금액·호가별 한도·분할 횟수를 기본값으로 싣지 않는다.
