# 실무 적용 패턴

이 파일의 표와 순서는 **스킬 작성자의 적용 양식**이다. 원문 원칙을 한 작업에 연결하는 용도이며 저자가 명명한 새 기법이나 자동 주문 규칙이 아니다. 세부 조건은 연결된 장·매매법을 읽는다.

## 장전 시장·후보 계획

**사용:** 매매 기법보다 시황을 먼저 정리할 때. [02장](chapters/ch02-market-perspective.md)·[03장](chapters/ch03-stock-selection.md).

| 항목 | 기록 |
|---|---|
| 관찰 시점·시장 | 날짜, 세션, 관찰 가능한 시간 |
| 시황 | 미국·국내 지수, 글로벌 변수, 외국인·기관 방향 |
| 돈의 흐름 | 주도 섹터/테마, 다른 곳에서 이동한 돈 |
| 재료 | 발생·후속 일정, 국내 종목과의 연결, 시장 반응 |
| 후보 | 거래대금+상승률, 위치, 호가, 유형별 대장 여부 |
| 제외 | 근거 소멸, 반반의 발표, 유동성·시간 제약 |
| 무기 | 적합한 기법과 관찰할 조건 |

**방법:** 시장 → 재료 → 후보 → 매매법 순으로 적는다. 미확인 항목은 비워두지 않고 ‘미확인’으로 표시한다.
**교환 관계:** 준비를 많이 해도 장중 돈의 방향은 달라질 수 있다. 후보 목록을 매수 약속으로 취급하지 않는다.

## 진입·무효화·대응 계획

**사용:** 실제 가격을 결정하기 전 근거와 철회를 연결할 때. [04장](chapters/ch04-five-weapons.md)·[06장](chapters/ch06-risk-and-capital.md).

| 항목 | 질문 |
|---|---|
| 매매 유형 | 종가/돌파/테마/수급/상따 중 무엇인가? |
| 진입 근거 | 어떤 시장·재료·수급·가격·속도를 확인했는가? |
| 진입 조건 | 무엇이 확인될 때 들어갈 것인가? |
| 무효화 | 근거가 깨졌다고 판단할 가격·수급·대장 신호는? |
| 비중 | 틀리면 감당할 손실과 실제 호가·청산 여건은? |
| 추가 매수 | 근거 강화인가, 평균단가를 낮추려는 변명인가? |
| 청산 | 목표한 움직임이 나왔을 때와 안 나왔을 때 대응은? |
| 중단 | 대응시간·유동성 부족 또는 시장 변화를 어떻게 처리할까? |

**방법:** 해당 상세 자료의 근거를 쓰고 별도 적용 조건을 구분한다. 손절률·수량·시간을 자료 없이 만들지 않는다.
**교환 관계:** 주문이 체결될 가격·갭·슬리피지는 계획대로 고정되지 않는다. 손절 계획과 최대 손실 보증은 다르다.

## 종가 베팅의 다음 날 분기

**사용:** 밤사이 보유와 출근 전 대응을 계획할 때. [종가](references/closing-bet.md)·[05장](chapters/ch05-worker-trading.md).

**원문 근거:** 세 갈래 자체는 저자의 서술이다. 저자는 종가 베팅 뒤 출근 전에 시나리오를 짜라고 하며, 갭 상승이면 어디서 분할 매도할지, 보합이면 어떤 가격을 기준으로 지켜볼지, 갭 하락이면 어디서 손절할지 계획하라고 한다(인쇄 221쪽 / PDF 217쪽). 아래에서 본업 시작 전 대응, 장기 보유로 바꾸지 않는 원칙([06장](chapters/ch06-risk-and-capital.md)), 관찰·주문이 불가능할 때의 보류는 스킬이 연결한 부분이다.

- **갭 상승:** 사전 계획한 분할 청산과 본업 시작 전 대응을 연결한다.
- **보합:** 핵심 가격과 원래 근거의 유지 여부를 확인한다.
- **갭 하락:** 사전 손절 조건을 적용하며 단기 진입을 장기 보유로 바꾸지 않는다.
- **관찰·주문 불가능:** 대응 가능한 방법을 확인하지 못했다면 매수 계획을 보류한다.

**적용 예시:** 장중 화면을 볼 수 없는 가상의 직장인이 거래대금 1위 테마주를 발견했다. 거래대금 외에 재료 지속, 실제 테마 대장, 종가 위치, 야간 일정, 다음 날 대응 여건을 확인하지 못했다면 ‘후보 관찰’로 기록한다. 이 예시는 저자의 실제 거래나 확정 매수 신호가 아니다.
**교환 관계:** 장중 관찰을 줄이는 대신 밤사이 위험과 다음 날 대응 준비가 필요하다.

## 손실 기준으로 비중 점검

**사용:** 좋은 종목이라는 이유로 감당하지 못할 금액을 넣으려 할 때. [06장](chapters/ch06-risk-and-capital.md).

1. 감당할 손실을 먼저 정한다.
2. 해당 매매법의 근거 무효화 가격·신호와 청산 가능성을 확인한다.
3. 호가 두께·세션·남은 대응시간을 함께 보고 매매 금액을 정한다.
4. 비중을 늘릴 때 시장의 확인과 감정의 추격을 구별한다.

가격 차이가 명확한 경우의 **추가 산술 양식**은 ‘계획 손실액 ÷ (주당 진입가와 손절가의 차이)’다. 저자가 이 계산식을 별도 기법으로 제시한 것은 아니다. 실제 계획에는 수수료·슬리피지·갭·미체결 여유가 필요하며 이 산술만으로 손실 상한이 보장되지 않는다.
**교환 관계:** 저자의 당시 호가·금액 사례를 사용자 계좌의 비율로 옮기지 않는다.

## 매매일지와 복기

**사용:** 손익만 적은 일지를 의사결정 기록으로 바꿀 때. [07장](chapters/ch07-routine-and-psychology.md)·[일지 상세](references/routines-and-journal.md).

- **그날의 시장:** 지수, 주도 섹터/테마, 외국인·기관·프로그램과 돈 이동.
- **진입 전:** 무엇을 보고 주도주라 판단했는지, 시간·가격·비중·철회 계획.
- **실제 대응:** 추가·감축·청산의 시점과 당시 관찰값.
- **결과와 비교:** 손익과 별개로 계획 준수, 놓친 기회, 다른 판단과의 차이.
- **다음 훈련:** 고칠 한 가지와 확인할 다음 관찰.

**방법:** 제삼자에게 설명할 수 있을 만큼 근거를 쓴다. 당시 정보와 사후에 알게 된 결과를 분리한다.
**교환 관계:** 일지 분량이 학습량은 아니다. 한 실패를 설명하지 못하면 수익 숫자를 늘려 적어도 해결되지 않는다.

## 직장인·전업 여건 점검

**사용:** 가용 시간과 본업·생활비를 함께 검토할 때. [05장](chapters/ch05-worker-trading.md).

| 항목 | 질문 |
|---|---|
| 동기·목표 | 왜 하는가? 가용 시간에 맞는 목표인가? |
| 실제 시간 | 장전·점심·퇴근 후·다음 날 중 언제 대응하는가? |
| 본업 | 매매 실패가 본업에 어떤 영향을 주는가? |
| 자금 분리 | 투자금·생활비·비상금이 분리되는가? 가족의 삶·건강·함께하는 시간과 시장을 구분하는가? |
| 전업 준비 | 책의 생활비 조건과 실제 지속 수익·심리 여건을 확인했는가? |
| 보류 조건 | 수익 압박·대출·통제 불가 위험이 있다면 어떻게 멈출까? |

**교환 관계:** 직장인의 낮은 관찰 빈도는 빠른 장중 대응을 요구하는 기법과 충돌한다. 전업 전환을 최근 수익 한 번으로 결정하지 않는다.
