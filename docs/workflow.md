# 학습·계획 검토·복기 흐름

아래는 여러 장을 연결한 **작성자의 활용 절차**입니다. 저자가 명명한 별도 트레이딩 기법이 아닙니다.

## 개념 학습

1. 주제와 원하는 설명 수준을 정합니다.
2. 장과 상세 참조를 읽고 개념·조건·예외·원문 위치를 확인합니다.
3. 가상 사례는 책의 실제 사례와 구별해 받습니다.
4. 이해 문제나 반례로 빠진 조건을 확인합니다.

## 매매 계획 검토

| 순서 | 자료 | 점검 |
|---|---|---|
| 시황과 관점 | 2장 | 돈의 흐름·가설·관찰 시점 |
| 후보 | 3장·선정 상세 | 주도 섹터 또는 강한 개별 재료·거래대금·상승률·자리·호가 |
| 매매법 | 4장·선택한 상세 자료 | 전략에 맞는 조건·근거·무효화 |
| 실행 여건 | 5장 | 관찰·다음 날 대응·본업 |
| 위험 | 6장 | 감당 손실·청산 여건·추가 매수 근거 |
| 기록 | 7장·패턴 | 당시 관찰·판단·계획 준수 |

미확인 항목은 새로운 숫자를 만들어 채우지 않습니다. 계획 검토에서는 “무엇이 확인되면 검토를 이어갈지, 무엇이 깨지면 보류·철회할지”까지 확인합니다. 자료만으로 확정 매매를 요구하지 않습니다.

## 일지 복기

당시 본 사실 → 사전 가설 → 실제 행동 → 결과 → 준수/위반 → 다음 훈련 한 가지로 정리합니다. 이익이 났다는 이유로 위반을 성공 규칙으로 바꾸지 않습니다. 사후 뉴스를 당시 매수 근거에 소급해서 넣지 않습니다. 원문 일지 항목은 [7장](../.agents/skills/danswer-market-trading/chapters/ch07-routine-and-psychology.md), 양식은 [패턴](../.agents/skills/danswer-market-trading/patterns.md)에서 확인합니다.

## 변경 후 확인

관찰 시간·전략·보유 조건을 바꾸면 그 변경만 먼저 표시하고, 진입·손절·다음 날 대응·본업·일지에 미치는 영향을 다시 확인합니다. 확정 조건과 미정 질문을 보존합니다. 자료나 지식 파일을 수정한 경우 이전 시험 결과를 새 버전의 통과 근거로 그대로 사용하지 않습니다.

새 적용·기존 문제 개선·변경 후 검증의 연결 요청은 [연계 시나리오](advanced-usage.md#scenarios)에 있습니다.

## 문장 교정 뒤 재확인

한국어 표현을 고칠 때는 humanizer→grammar-checker→style-guide 순으로 점검합니다. 자연스럽게 줄인 문장에서 수치·기간·부정·조건·예외·귀속이 사라지지 않았는지 원문과 비교합니다. 최종 고정 뒤에는 교정하지 않습니다. 고정 전 보완으로 내용이 바뀌면 관련 정적·사용 시험을 다시 수행합니다.
