# 문제 해결

| 문제 | 확인 | 해결 |
|---|---|---|
| 스킬이 목록에 없다 | 현재 프로젝트·새 대화·`SKILL.md` 위치 | 프로젝트를 다시 확인하고 아래 읽기 요청 실행 |
| 참조 자료를 못 읽는다 | 폴더 전체 설치 여부·파일명 | 장·참조·보조 파일 전체를 함께 설치 |
| Claude에서 찾지 못한다 | 개별 링크 대상과 원본 | 기존 항목을 보존하며 올바른 상대 링크 연결 |
| Claude가 질문만으로 스킬을 쓰지 않는다 | 설치한 스킬이 많으면 목록에서 설명이 생략될 수 있음 | `/danswer-market-trading`으로 직접 호출 |
| 원본 PDF와 대조하고 싶다 | 스킬은 기본적으로 스킬 폴더 자료로만 답함 | 원본 파일 위치와 확인할 쪽을 함께 알려 주며 대조를 요청 |
| 최신 세션·번호를 단정한다 | 책의 과거 설명과 현재 자료 구별 | 현재 증권사/거래소 자료의 출처·시점을 별도 제공 |
| 계획에 숫자가 과하게 생긴다 | 입력과 가정 표기 | 미입력 값은 미확인으로 남기고 근거·철회만 먼저 요청 |
| 모든 기법의 조건이 같다 | 4장만 읽고 상세를 생략했는가 | 선택한 매매법의 상세 참조를 먼저 읽게 요청 |
| PDF쪽이 맞지 않는다 | 다른 판본·파일 해시·단일 offset 사용 | `source.json`과 구간별 쪽 대응 확인 |
| 표·차트 글자가 불확실하다 | 텍스트 추출과 이미지 차이 | 접근 가능한 원문의 해당 쪽을 직접 판독. 미확인은 유지 |
| 답변이 너무 길다 | 범위·산출물 수 | 현재 선택한 기능의 표 하나나 미확인 항목만 요청 |

## 직접 읽기 확인

```text
현재 프로젝트의 .agents/skills/danswer-market-trading/SKILL.md를 읽고
종가 베팅 요청에 필요한 장과 상세 참조 파일이 실제로 있는지 확인해줘.
그 자료를 읽은 뒤 후보·무효화·다음 날 대응의 관계만 설명해줘.
```

이 요청이 동작하면 지식 파일 접근과 목록 발견을 구분할 수 있습니다. 다른 프로젝트를 자동으로 수정하거나 전역 스킬 사본을 덮어쓰는 해결책은 사용하지 않습니다.

## 추가 원문 확인이 필요한 경우

확인할 주장·인쇄/PDF 위치·현재 스킬의 해당 문장을 좁혀 제공합니다. 원문 파일이 없으면 그 상태를 밝히고 미확인으로 남깁니다. 이미 기록한 원문 모호함을 수치나 가격 간격으로 메우지 않습니다. [검수 기준](validation.md)과 [자료 색인](../.agents/skills/danswer-market-trading/references/index.md)을 함께 봅니다.
