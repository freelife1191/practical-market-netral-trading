# 사용 가이드

처음이면 [시작하기](getting-started.md)에서 한 요청을 실행하고, [고급 활용](advanced-usage.md)에서 필요한 장의 예시로 이어갑니다. 전체 구성과 설치는 [README](../README.md)에 있습니다.

| 현재 목적 | 읽을 문서 | 다음 산출물 |
|---|---|---|
| 개념을 배우고 싶다 | [시작하기](getting-started.md) → [고급 활용](advanced-usage.md#chapter-2) | 개념·새 예시·이해 확인 |
| 계획의 조건을 점검하고 싶다 | [작업 흐름](workflow.md) → [검수](validation.md) | 근거·미확인·보류·철회 |
| 일지를 개선하고 싶다 | [7장 활용](advanced-usage.md#chapter-7) | 의사결정 기록과 훈련 |
| 다른 호스트에서 사용한다 | [에이전트별 사용](agents.md) | 설치·호출·인식 확인 |
| 문서·스킬을 못 찾는다 | [문제 해결](troubleshooting.md) | 원인별 복구 |

지식의 정본은 [스킬 폴더](../.agents/skills/danswer-market-trading/SKILL.md), 사용자 안내의 정본은 루트 README와 이 가이드입니다. `book-to-skill-followup`은 후속 제작 도구이며 일상적인 책 학습에는 `danswer-market-trading`을 호출합니다.
