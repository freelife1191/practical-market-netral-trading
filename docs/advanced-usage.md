# 고급 활용과 장별 프롬프트

이 가이드는 작성자가 설계한 학습·검토 요청 모음입니다. **본문 7장 + 부록 + 프롤로그 + 에필로그**의 10개 활용 단위에 각각 예시 2개·후속 요청 1개를 제공합니다. 공통 예시 4개·연계 시나리오 3개에 매매법별 심화 예시 5개·후속 요청 5개를 더해 **고급 예시 32개·후속 요청 15개**입니다.

목차는 구조 확인용이며 별도 매매 활용 예시를 만들지 않습니다. 수익인증은 프롤로그의 오용 검토에서 자료 한계를 다루며 실적 인증·화면 복제·전략 통계 추정을 제외합니다. 각 프롬프트 ID는 문서 검토와 시험 선택을 위한 작성자 식별자입니다.

## 사용 방법

코드 블록을 대화창에 붙여 넣습니다. 가상 입력을 실제 자료로 바꾸면 관찰 시점·출처와 확정/미정 조건을 함께 제공합니다. Codex의 `$`는 Claude Code에서 `/`로, Antigravity에서는 스킬 이름을 포함한 자연어로 바꿉니다. 같은 대화의 후속 요청은 실제로 선택한 예시 A 또는 B의 결과를 바탕으로 이어집니다. 새 대화에서는 이전 결과를 함께 제공합니다.

개념 학습은 설명, 자료 탐색은 파일·원문 위치 안내, 계획 검토는 판단·근거·미확인·대응 조건을 요청합니다. HTS처럼 별도 참조로 충분한 주제는 그 자료부터 읽습니다. 원문 사례를 읽을 때는 종목명뿐 아니라 사례 번호·거래 날짜·인쇄/PDF쪽을 확인합니다. 후속 요청에서 가정을 추가하면 원문 당시의 실제 결과와 별도로 표시합니다.

## 공통 고급 예시

<a id="common-1"></a>

### 자료 선택 · `common-1`

```text
$danswer-market-trading 가상 요청: 직장인의 종가 후보 선정·손절·복기에 필요한 자료를 찾고 싶다.
참조 색인에서 필요한 장과 상세 자료를 골라 질문→읽을 파일/절→원문 범위→기대 산출물 표를 작성해줘.
전체 책을 읽거나 현재 후보를 발명하지 마. 종목·날짜·가격·시간은 미정이다.
책의 개념·원문 사례·작성자 양식을 어떤 순서로 읽을지 설명해줘.
```

**기대 결과·검토 기준:** 실제 파일 경로와 선택 이유가 있고 요약표만으로 조건을 확정하지 않는다.

<a id="common-2"></a>

### 같은 조건의 대안 비교 · `common-2`

```text
$danswer-market-trading 가상 입력: 후보는 재료가 있지만 연속성·유동성은 미확인이고 장중 대응이 어렵다.
같은 입력을 유지한 채 종가 접근·장중 돌파·관망을 비교해줘. 관련 상세 참조와 5·6장을 읽어줘.
선택지마다 필요한 자료·가용 시간·야간 위험·무효화·보류 이유를 붙여줘.
비교 과정에서 손절률·후보 강도·주문 수량을 유리한 값으로 바꾸지 마.
```

**기대 결과·검토 기준:** 같은 조건을 유지하며 누락 입력을 각 대안에 동일하게 적용한다.

<a id="common-3"></a>

### 변경 영향 · `common-3`

```text
$danswer-market-trading 가상 계획의 확정 조건은 업무 중 주문 금지·생활비 분리이며, 변경안은 다음 날 출근 전 확인도 불가능해진 것이다.
5장·종가 상세·6장을 읽고 기존 확정 조건을 유지하며 보유 대응·신규 후보·보류·일지의 영향을 점검해줘.
주문 가능한 대안 수단은 미정이며 자동 청산이 가능하다고 가정하지 마.
산출물은 변경 전제→영향→추가 확인→보류·철회와 회귀 시나리오 표야.
```

**기대 결과·검토 기준:** 변경된 관찰 여건만 반영하며 임의 자동 주문 설정을 해결책으로 만들지 않는다.

<a id="common-4"></a>

### 산출물 일관성 검토 · `common-4`

```text
$danswer-market-trading 가상 문서에는 후보표의 “관찰만”, 계획표의 “매수 확정”, 일지의 “사후 뉴스가 진입 근거”가 동시에 있다.
2·3·6·7장과 패턴을 읽어 세 표의 판단·근거·관찰 시점·미확인·철회 조건을 검토해줘.
원본 문장을 보존한 채 위치→모순→영향→수정안을 적어줘. 실제 시장 정보·가격은 미정이다.
새 판단을 작성자 제안으로 표시하고 현재 종목 매수 여부를 단정하지 마.
```

**기대 결과·검토 기준:** 당시 근거와 사후 설명, 후보와 실행을 구별한 추적 가능한 검토표.

**읽을 자료:** [chapters/ch01-survival-and-learning.md](../.agents/skills/danswer-market-trading/chapters/ch01-survival-and-learning.md) · [참조 색인](../.agents/skills/danswer-market-trading/references/index.md)

<a id="chapter-1-a"></a>

### 예시 A — 기법 갈아타기를 멈추는 학습 계획 · `chapter-1-a`

```text
$danswer-market-trading 가상 입력: 손실 3번 뒤 새 기법을 찾고 연습금도 늘리려는 초보자가 있다.
1장을 먼저 읽고, 한 기법 관찰→사전 근거→비교 학습→복기의 훈련 계획을 작성해줘.
돈이 부족한 문제와 기준이 없는 문제를 구분하고, 손실 만회 입금·미수·주문 복제를 점검해줘.
관찰 기간·연습 금액·손절률은 미정이다. 저자의 개인 기간·금액을 내 기본값으로 넣지 마.
산출물은 훈련 단계·기록할 항목·중단 조건 표와 이해 확인 질문 3개로 해줘.
```

**기대 결과·검토 기준:** 한 기법에 조건과 반증을 연결한 계획. 성과·금액·타인 주문이 학습 기준을 대신하지 않아야 한다.

<a id="chapter-1-b"></a>

### 예시 B — 카피 트레이딩 메모의 귀속 검토 · `chapter-1-b`

```text
$danswer-market-trading 가상 메모: “잘하는 사람과 같은 종목을 같은 금액으로 사면 배우는 것이다.”
1장 근거로 이 메모를 주장→문제→학습용 수정안으로 검토해줘.
저자의 실제 비교 학습 사례와 작성자가 제안한 양식을 구분하고 원문 위치를 붙여줘.
동료의 계좌·실시간 주문·매매 신호를 제공받지 않은 상태이며 수익 가능성은 판단하지 마.
수정안에는 같게 본 조건·다르게 본 이유·내 독립 청산 계획을 비교할 항목을 넣어줘.
```

**기대 결과·검토 기준:** 타인 주문 복제와 관점 학습이 구분되고 개인 숙련 사례를 보편 기준으로 바꾸지 않는 검토표.

### 예시 A — 빈칸을 허용하는 2-2-2 후보표 · `chapter-2-a`

```text
$danswer-market-trading 가상 입력: 글로벌 관심 분야 후보 2개, 국내 테마 후보 1개, 개별 이슈 후보 1개만 관찰됐다. 이름은 G1·G2·T1·I1이다.

2-2-2의 원문 설명과 이 가상 후보표를 구분해줘. 수량을 채우기 위해 새 종목을 발명하지 마.
```

### 예시 B — 관점이 맞아도 실행이 틀린 복기 · `chapter-2-b`

```text
$danswer-market-trading 가상 일지: “반도체로 돈이 모일 것이라 예상했고 실제로 강했지만, 이미 오른 종목을 추격했고 매도 기준은 없었다.”
2장으로 시황 판단·종목/자리 선택·청산 계획을 나누어 검토해줘.
당시 관찰 사실과 결과 뒤 설명을 구분하고, 원문 성공/실패 사례의 교훈을 조건별로 비교해줘.
현재 종목과 실제 수익 데이터는 없으며 원문 개인 손절률·목표가를 내 규칙으로 복제하지 마.
산출물은 문제→영향→다음 사전 시나리오의 수정 항목 표야.
```

**기대 결과·검토 기준:** 관점 적중이 진입·청산 적절성을 증명하지 않는다는 검토와 객관적 무효화 질문.

<a id="chapter-3-a"></a>

### 예시 A — 거래대금 1위와 빠른 테마 대장 비교 · `chapter-3-a`

```text
$danswer-market-trading 가상 입력: A는 거래대금 1위지만 상승률이 약하고, B는 같은 테마에서 가장 빨리 상승했지만 호가가 얇다. 두 종목의 재료 지속성과 가격 위치는 미확인이다.
3장·선정 상세·테마 상세를 읽고 일반 주도주 선정과 빠른 테마 대장 기준을 구별해줘.
다섯 조건별 확인/미확인/제외 검토표와 유형별 추가 관찰 질문을 만들어줘.
A/B 중 매수할 종목을 단정하거나 주문 규모·현재 재료를 발명하지 마.
0순위는 관찰 후보임을 유지하고 호가 두께를 내 주문 규모와 연결해줘.
```

**기대 결과·검토 기준:** 대장 기준을 유형별로 나누고 얇은 호가를 자동 제외 또는 자동 기회로 보지 않는 후보표.

<a id="chapter-3-b"></a>

### 예시 B — 프로그램·거래원을 혼동한 주장 비판 · `chapter-3-b`

```text
$danswer-market-trading 가상 주장: “프로그램 순매수와 특정 증권사 창구 매수가 있으니 외국인이 장기 보유할 것이다.”
3장·선정 상세·수급 상세를 읽고 숫자·주체·지속성·가격 반응을 나누어 검토해줘.
저자가 복잡한 누적 금액 계산 대신 당일 수량·방향을 매일 보는 관찰법과 일별 매수 연속성을 확인하는 방법을 설명해줘. 원문이 직접 설명하지 않은 이유를 저자의 발언으로 만들지 마.
각 추론에 확인된 사실, 추가 자료, 현재 단정할 수 없는 것을 표시해줘.
특정 창구의 실제 고객·뉴스·시간별 수급은 미입력이다. 실제 주체나 지속 매수를 확정하지 마.
거래원입체분석 번호를 언급하면 원문 본문과 화면/부록의 차이를 함께 적어줘.
```

**기대 결과·검토 기준:** 당일 수량·방향과 일별 연속성을 구분하며 복잡한 누적 금액을 필수로 만들지 않는다. 프로그램·거래원으로 실제 주체를 확정하지 않고 원문 번호 차이를 보존한다.

<a id="chapter-3-followup"></a>

### 후속 요청 · `chapter-3-followup`

```text
$danswer-market-trading 앞선 3장 답변을 이어서 보완해줘.
후보표를 선택했다면 0순위 관찰의 유지·교체 조건을 추가해줘. 저자의 관심 종목 제외 기준을 일반 자동 매도 규칙으로 바꾸지 마.

```

**기대 결과·검토 기준:** 앞선 A/B 선택에 맞는 기록표만 추가한다. B의 미확인 수급을 확정값으로 바꾸거나 A의 관심 종목 기준을 매도 신호로 옮기지 않는다.

## 4장 — 다섯 가지 무기의 선택

**활용 시점:** 시장·시간에 맞는 기법을 고르거나 전략별 조건이 섞인 초안을 점검할 때. 다섯 상세 참조를 필요한 만큼 함께 읽는다.

**읽을 자료:** [chapters/ch04-five-weapons.md](../.agents/skills/danswer-market-trading/chapters/ch04-five-weapons.md) · [참조 색인](../.agents/skills/danswer-market-trading/references/index.md)

**연계:** 2장·3장·5장·6장. 원문 범위는 연결 자료의 머리말과 [쪽 대응](../.agents/skills/danswer-market-trading/references/source-map.md)에서 확인합니다.

```text
$danswer-market-trading 가상 입력: 주도 섹터의 후보가 전고점 부근에 있고 거래대금이 유지되지만, 장중 관찰은 불가능하고 다음 날 출근 전 15분만 대응할 수 있다. 밤사이 일정은 미확인이다.
4장·종가 상세·돌파 상세·5장을 읽고 같은 조건에서 두 접근의 필요 관찰·진입 근거·무효화·보류 이유를 비교해줘.
종가에 산다는 사실만으로 종가 베팅이 성립한다고 판단하지 마.
가격·비중·다음 날 거래 가능한 세션은 미정이다. 책의 시간대를 현재 운영 사실로 넣지 마.
산출물은 비교표와 추가 확인 순서, 관망을 포함한 조건부 결론이야.
```

**기대 결과·검토 기준:** 장중 대응과 밤사이 위험의 차이가 드러나며 현재 조건으로 매수를 확정하지 않는다.

<a id="chapter-4-b"></a>

### 예시 B — 테마·수급·상따의 청산 규칙 혼합 검토 · `chapter-4-b`

```text
$danswer-market-trading 가상 초안: “모든 기법은 처음 70% 진입, 프로그램 순매수면 유지, 대장 상한가 후 10분에 모두 청산, 약하면 100분할 물타기.”
4장과 종가·테마·수급·상따·돌파 상세, 6장을 읽고 전략별로 잘못 합친 부분을 분리해줘.
원문 수치가 나오는 전략·상황·기준점을 적고 일반 규칙과 개별 예외를 구별해줘.
종가의 투매 100분할과 사전 라운드 피겨 손절, 수급주의 1억 원·100만 원씩 최대 100회 예시, 미정 가격 간격을 구별해줘. 테마의 서로 다른 상한가 상황도 구별해줘.
산출물은 주장→해당 참조→모순/미확인→수정 방향 표야. 주문 알고리즘은 만들지 마.
```

**기대 결과·검토 기준:** 전략 간 비중·청산·수급 조건을 합치지 않고 숫자의 문맥과 미정 기준점을 유지한다.

### 후속 요청 · `chapter-4-followup`

```text
앞선 비교나 규칙 수정안에서 선택한 전략이 있으면 그 전략의 진입·무효화·다음 대응 표를 추가해줘. 관망·보류 결론이었다면 이를 유지하고 검토를 재개할 확인 조건만 적어줘.
다른 전략 조건을 복사하거나 앞선 미확인을 확정값으로 바꾸지 마.
```

**기대 결과·검토 기준:** 이전 선택과 확정 조건을 유지하고, 현재 결과에서 다룬 항목만 구체화한다.

### 종가 — 고유 근거·다음 날 결과·거래 식별 · `reference-closing`

```text
$danswer-market-trading 한화시스템·펄어비스·광주신세계, SK하이닉스·삼성전자-2(2026-05-25)와 -3(2026-07-14~15)의 종가 사례를 비교해줘.
```

```text
“높은 판매량이나 상한가만 있으면 같은 비중으로 산다”, “사후 해외 급등은 진입 근거였다”, “상한가까지 보유했으니 정확한 매도값도 안다”를 원문 근거에 맞게 고쳐줘.

원문 거래 날짜·CPI/PPI 차이·미기재 값을 유지하고 가상 후보를 과거 사례와 섞거나 매수를 확정하지 마.
```

**기대 결과·검토 기준:** 앞선 표의 근거로 요약 오류를 고친다. 가상 후보는 별도로 검토하며 정규장 전용을 프리·애프터 지원으로 바꾸거나 기존 사례의 비중을 복사하지 않는다.

### 돌파 — 매드업의 시황과 네 묶음 점검 · `reference-breakout`

**읽을 자료:** [돌파 상세](../.agents/skills/danswer-market-trading/references/breakout.md) · [6장](../.agents/skills/danswer-market-trading/chapters/ch06-risk-and-capital.md).

```text
$danswer-market-trading 매드업 사례에서 삼성전자 전일 종가 이탈→신규주 자금 이동→당일 고가 재돌파가 어떻게 연결됐는지 설명해줘.
4장·돌파 상세를 읽고 인쇄/PDF쪽과 원문에 없는 청산값을 표시해줘. 신규주 전체가 지수와 항상 반대로 움직인다고 일반화하지 마.
별도 가상 후보: 주도성·돌파 가격·거래대금 증가는 관찰했지만 반복 매물 소화와 지지는 미확인이다. 장중 관찰은 가능하고 손절가는 정했으나 다음 목표 가격은 미정이다.
주도주·돌파 가격·돌파 힘·타이밍의 네 묶음으로 이 가상 후보를 점검하고, 손익비를 판단하는 데 빠진 입력을 적어줘.
일부 통과로 진입을 확정하거나 원문에 없는 고정 손익비·매드업의 당시 가격을 가상 주문값으로 넣지 마.
```

**기대 결과·검토 기준:** 매드업의 당시 시황과 가상 후보를 분리한다. 매물 소화·지지와 다음 목표가 미확인이면 네 묶음 전체 충족·충분한 손익비를 확정하지 않는다.

<a id="reference-breakout-followup"></a>

#### 후속 요청 · `reference-breakout-followup`

```text
$danswer-market-trading 방금 가상 후보 점검을 이어서 보완해줘.
추가 관찰은 반복 매물 소화와 가격 위 지지 확인이며, 다음 목표 가격은 여전히 미정이다. 다른 확정·미확인 조건은 유지해줘.
무엇이 해소됐고 무엇 때문에 아직 보류하는지 네 묶음 표를 갱신해줘. 필요한 다음 입력과 근거가 깨질 때의 철회를 적어줘.
손익비 숫자나 자동 매수 신호를 새로 만들지 말고 매드업 사례의 결과를 가상 후보의 미래로 옮기지 마.
```

**기대 결과·검토 기준:** 새로 확인된 힘만 반영하며 목표 가격·손익비의 미확인을 유지한다. 지지 확인만으로 진입 가능으로 바꾸지 않는다.

### 테마 — 세션별 재강화와 후속주 보유 · `reference-theme`

**읽을 자료:** [테마 상세](../.agents/skills/danswer-market-trading/references/theme-trading.md).

```text
$danswer-market-trading 로보티즈·LG 사례를 로보스타의 정규장과 대체거래소 흐름을 중심으로 설명해줘.
4장·테마 상세를 읽고 상한가 이탈→보합→대체거래소 재상한가가 왜 테마의 힘을 판단하는 근거였는지, LG 시가 매매까지 어떻게 확장됐는지 정리해줘.
대장·후속주와 세션을 구별하고 인쇄/PDF쪽을 붙여줘. 본문에 없는 다음 날 청산값은 미기재로 남겨줘.
일반 청산 기준은 대장 상한가 뒤 후속주 관찰, 후속주 자체 상한가, 강한 테마의 예외로 나누어 설명해줘.
거래대금 1위를 자동 대장으로 삼거나 이 사례를 모든 재상한가의 성공 공식으로 만들지 마.
```

**기대 결과·검토 기준:** 첫 상한가와 이탈 뒤 재강화, 세션의 차이를 보존한다. 대장 상한가 뒤 보통 1–2분과 후속주 자체 상한가 뒤 최대 10분, 강한 테마의 보유 예외를 혼동하지 않는다.

<a id="reference-theme-followup"></a>

#### 후속 요청 · `reference-theme-followup`

```text

가상 후속주는 아직 상한가가 아니고 대장은 재상한가 뒤 멈칫하며 내려왔다. 동류 종목의 변동성 유지 여부는 미확인이다.
대장의 속도·멈칫함에 따른 철회와, 강한 테마 예외를 적용하기 위해 필요한 관찰을 나눠줘.
원문의 1–2분이나 10분을 무조건 기다리는 시간으로 바꾸지 말고 고정 손절률·다음 날 보유 근거를 만들지 마.
```

**기대 결과·검토 기준:** 재상한가가 있었다는 사실만으로 약해진 대장을 무시하지 않는다. 강한 테마가 미확인이면 보유 예외를 확정하지 않고 시간 규칙을 손절 지연의 이유로 쓰지 않는다.


**기대 결과·검토 기준:** 일정·당시 기대·실제 수급·사후 결과를 나눈다. 복잡한 누적 금액 계산이나 미공개 정보 보유를 전제하지 않고 저자의 설명과 작성자 양식을 구분한다.

**읽을 자료:** [references/hts-setup.md](../.agents/skills/danswer-market-trading/references/hts-setup.md) · [참조 색인](../.agents/skills/danswer-market-trading/references/index.md)

**연계:** 2장·3장·7장. 원문 범위는 연결 자료의 머리말과 [쪽 대응](../.agents/skills/danswer-market-trading/references/source-map.md)에서 확인합니다.

<a id="appendix-a"></a>

### 예시 A — 관찰 전용 화면 구성 · `appendix-a`

```text
$danswer-market-trading 가상 입력: 노트북 한 화면에서 종목 찾기·시장 흐름·후보 판단을 관찰하려 한다. 실제 주문은 하지 않는다.
HTS 부록과 3장을 읽고 질문→정보→원문 창 예시→확인할 갱신 시각으로 배치를 제안해줘.
현재 HTS 버전·접근 권한은 미정이다. 원문 번호를 현재 기능 보증으로 쓰지 마.
저자의 모니터 수나 원클릭 주문 설정을 필수로 복제하지 말고 산출물은 목적별 화면표와 제거 기준이야.
```

**기대 결과·검토 기준:** 개인 세팅을 필수 장비 사양으로 승격하지 않고 관찰 목적과 주문 기능을 구분한다.

<a id="appendix-b"></a>

### 예시 B — 거래원 번호와 세션의 현재성 검토 · `appendix-b`

```text
$danswer-market-trading 가상 초안: “거래원은 0218만 맞고, 책의 프리·정규·애프터 시간은 오늘 모든 종목에도 적용된다.”
부록·3장·쪽 대응을 읽어 원문 번호 차이와 집필 시점 세션 설명을 검토해줘.
원문 본문·화면·부록의 위치를 각각 적고 어떤 현재 자료가 추가로 필요한지 정리해줘.
실제 증권사 버전·거래일·대체거래소 대상은 미입력이다. 현재 번호·운영 시간을 확정하지 마.
산출물은 주장→근거→한계→확인 항목 표야.
```

**기대 결과·검토 기준:** 원문 내부 불일치와 외부 현재성 문제를 구분하고 양쪽 근거를 보존한다.

<a id="appendix-followup"></a>

### 후속 요청 · `appendix-followup`

```text
$danswer-market-trading 앞선 부록 답변을 이어서 보완해줘.
선택한 화면 배치 또는 주장 검토에서 필요한 창 3개만 남겨줘. 각 창이 답하는 질문과 아직 확인하지 못한 환경 조건을 붙여줘.
```

**기대 결과·검토 기준:** 이전 선택과 확정 조건을 유지하고, 현재 결과에서 다룬 항목만 구체화한다.

**기대 결과·검토 기준:** 제시된 계좌 자료와 독립적으로 검증한 전략 통계를 구분한다.

### 신규 적용 — 장전부터 복기까지 · `scenario-1`

```text
$danswer-market-trading 가상 입력: 신규 학습자는 장전 20분·장후 30분만 사용 가능하고 장중은 못 본다.
2장→3장→종가 상세/5장→6장→7장의 순서로 학습용 작업 묶음을 만들어줘.
각 단계의 입력·산출물·다음 단계로 넘길 확인 조건을 표로 작성해줘.
시황 데이터·후보·가격·위험 금액·현재 거래 세션은 미정이다. 후보 관찰과 실제 진입은 분리하고 비어 있는 값은 미확인으로 유지해줘.
```

**기대 결과·검토 기준:** 연결된 자료 선택·후보·조건·여건·위험·복기 계획. 단계별 미확인이 뒤에서 확정값으로 변하지 않아야 한다.

### 기존 문제 개선 — 복구 욕구가 섞인 일지 · `scenario-2`

```text
$danswer-market-trading 가상 입력: “관심 순위가 높아서 추격했다. 손실 뒤 월급을 입금하고 물타기했다. 결국 이익이라 같은 방식으로 금액을 키우겠다.”
1장→3장→6장→7장을 읽고 동기·선정 근거·추가 매수·결과 해석의 문제를 분리해줘.
가상 기록의 원문을 보존하고 문제→관련 근거→중단/복기 방향→다음 훈련 한 가지 표로 개선해줘.
실제 계좌·손절률·금액은 미입력이며 성과를 검증한 것으로 취급하지 마.
```

**기대 결과·검토 기준:** 수익 결과가 규칙 위반을 정당화하지 않는 개선안과 추가 확인 기록.

```text
$danswer-market-trading 가상 변경: 종가 학습에서 빠른 테마 짝꿍 관찰로 옮기려 한다. 업무 중 대응 금지·생활비 분리는 확정이고 장중 연속 관찰은 미정이다.
```
